RR I rzędu — typy i rozpoznawanie

Egzamin Zad. 5 Teoria  &sstrok; ~35 min

Równania różniczkowe I rzędu to Zad. 5 na egzaminie praktycznym. Klucz: rozpoznaj typ → zastosuj odpowiednią metodę. Ta lekcja uczy rozpoznawania typów i rozwiązywania najprostszych (zmienne rozdzielone). Definicje z WYKŁADU równania I rzędu.

Segment 1: Co to jest RR I rzędu?

Definicja — Równanie różniczkowe I rzędu  [WYKŁAD RR I rz.]

Równanie w postaci normalnej:

\[y' = f(x, y)\]

Szukamy funkcji \(y = y(x)\) takiej, że \(y'(x) \equiv f\bigl(x, y(x)\bigr)\).

Definicja — Zagadnienie Cauchy'ego (warunek początkowy)
\[y' = f(x,y), \qquad y(x_0) = y_0\]

Szukamy rozwiązania przechodzącego przez punkt \((x_0, y_0)\).

Twierdzenie — Istnienie i jednoznaczność  [WYKŁAD RR I rz.]

Jeśli \(f(x,y)\) i \(\frac{\partial f}{\partial y}(x,y)\) są ciągłe na obszarze \(D \ni (x_0,y_0)\), to zagadnienie Cauchy'ego ma dokładnie jedno rozwiązanie.

Na egzaminie

Zwykle dostajesz równanie + warunek początkowy. Algorytm: (1) rozpoznaj typ, (2) znajdź rozwiązanie ogólne (z \(C\)), (3) wyznacz \(C\) z warunku.

Segment 2: Cztery typy równań I rzędu

Typ 1: Zmienne rozdzielone (ZR)

Postać
\[y' = g(x) \cdot h(y)\]

Prawa strona jest iloczynem funkcji samego \(x\) i funkcji samego \(y\).

  1. Jeśli \(h(y_0) = 0\), to \(y \equiv y_0\) jest rozwiązaniem (stała)
  2. Dla \(h(y) \neq 0\): rozdziel zmienne: \(\frac{dy}{h(y)} = g(x)\,dx\)
  3. Scałkuj obie strony: \(\int\frac{dy}{h(y)} = \int g(x)\,dx + C\)
  4. Wyraź \(y(x)\) jeśli się da (lub zostaw w postaci uwikłanej)
Przykład — \(y' = xy^2\)

Tutaj \(g(x) = x\), \(h(y) = y^2\). Rozwiązanie stałe: \(y \equiv 0\).

Dla \(y \neq 0\): \(\frac{dy}{y^2} = x\,dx\), więc \(-\frac{1}{y} = \frac{x^2}{2} + C\), czyli:

\[y = \frac{-1}{\frac{x^2}{2} + C} = \frac{-2}{x^2 + C_1}\]

Typ 2: Jednorodne (J)

Postać
\[y' = g\!\left(\frac{y}{x}\right)\]

Prawa strona zależy wyłącznie od ilorazu \(y/x\).

  1. Podstaw \(u = \frac{y}{x}\), czyli \(y = ux\), \(y' = u'x + u\)
  2. Równanie staje się: \(u'x + u = g(u)\), czyli \(u'x = g(u) - u\)
  3. To jest ZR ze zmiennymi \(u\) i \(x\): \(\frac{du}{g(u)-u} = \frac{dx}{x}\)
  4. Scałkuj, wróć do \(y = ux\)
Jak rozpoznać?

Sprawdź: czy po podzieleniu licznika i mianownika przez odpowiednią potęgę \(x\) (lub \(y\)) wszystko da się wyrazić przez \(y/x\)?

Np. \(y' = \frac{y^2 + xy}{x^2}\) = \(\frac{(y/x)^2 + (y/x)}{1} = g(y/x)\) ✓

Typ 3: Liniowe (L)

Postać
\[y' + p(x)\,y = q(x)\]

\(y\) i \(y'\) występują liniowo (w pierwszej potędze). Współczynniki zależą tylko od \(x\).

  • \(q(x) \equiv 0\): jednorodne liniowe (LJ) — jest to ZR!
  • \(q(x) \neq 0\): niejednorodne liniowe (LN)
  1. Rozwiąż jednorodne (\(q=0\)): \(y_J = Ce^{-\int p(x)\,dx}\)
  2. Uzmienniaj stałą: \(y = C(x)\cdot e^{-\int p(x)\,dx}\)
  3. Wstaw do pełnego równania, wyznacz \(C(x)\)
  4. Ogólne rozwiązanie: \(y = e^{-\int p\,dx}\!\left(\int q\,e^{\int p\,dx}\,dx + C\right)\)

Typ 4: Bernoulliego (B)

Postać
\[y' + p(x)\,y = q(x)\,y^r, \qquad r \neq 0,\; r \neq 1\]

Jak liniowe, ale z \(y^r\) po prawej. Dla \(r = 0\) to LN, dla \(r = 1\) to LJ.

  1. Jeśli \(r > 0\): \(y \equiv 0\) jest rozwiązaniem
  2. Podziel przez \(y^r\): \(y^{-r}y' + p(x)\,y^{1-r} = q(x)\)
  3. Podstaw \(z = y^{1-r}\), \(z' = (1-r)y^{-r}y'\)
  4. Dostaniesz równanie liniowe na \(z\): \(z' + (1-r)p(x)\,z = (1-r)q(x)\)

Algorytm rozpoznawania typu

Drzewo decyzyjne
  1. Czy \(y' + p(x)y = q(x)y^r\) z \(r \neq 0,1\)? → Bernoulli (podstaw \(z = y^{1-r}\))
  2. Czy \(y' + p(x)y = q(x)\) (liniowe w \(y\))? → Liniowe (uzmiennianie stałej)
  3. Czy \(y' = g(x) \cdot h(y)\) (iloczyn)? → Zmienne rozdzielone
  4. Czy \(y' = g(y/x)\)? → Jednorodne (podstaw \(u = y/x\))

Na egzaminie najczęściej: liniowe lub zmienne rozdzielone. Bernoulli i jednorodne rzadziej, ale się zdarzają.

Przykład rozwiązany: ZR z warunkiem  (Lista 4, Zad. 4.2a)

Zadanie
\[y\,dx + \ctg x\,dy = 0, \qquad y\!\left(\frac{\pi}{3}\right) = 1\]
Rozwiązanie

Krok 1 — Przepisz w postaci normalnej:

\[y\,dx = -\ctg x\,dy \implies \frac{dy}{dx} = -\frac{y}{\ctg x} = -y\tg x\]

To jest ZR: \(g(x) = -\tg x\), \(h(y) = y\). (To też liniowe jednorodne!)

Krok 2 — Rozdziel i scałkuj:

\[\frac{dy}{y} = -\tg x\,dx\] \[\int\frac{dy}{y} = -\int\tg x\,dx\] \[\ln|y| = \ln|\cos x| + C_1\] \[|y| = e^{C_1}|\cos x| \implies y = C\cos x\]

Krok 3 — Warunek początkowy:

\[y\!\left(\frac{\pi}{3}\right) = 1: \quad 1 = C\cos\frac{\pi}{3} = \frac{C}{2} \implies C = 2\]

Odpowiedź: \(\boxed{y = 2\cos x}\)

Przykład rozwiązany: Jednorodne  (Lista 4, Zad. 5.1a)

Zadanie
\[x\frac{dy}{dx} = x + y\]
Rozwiązanie

Krok 1 — Rozpoznaj typ:

\[y' = \frac{x + y}{x} = 1 + \frac{y}{x} = g\!\left(\frac{y}{x}\right) \quad\text{✓ jednorodne}\]

Krok 2 — Podstawienie \(u = y/x\):

\(y = ux\), \(y' = u'x + u\). Wstawiamy:

\[u'x + u = 1 + u \implies u'x = 1 \implies u' = \frac{1}{x}\]

Krok 3 — Scałkuj:

\[u = \ln|x| + C\]

Krok 4 — Wróć do \(y\):

\[y = ux = x(\ln|x| + C) = \boxed{x\ln|x| + Cx}\]

Rozgrzewka: Rozpoznaj typy

Dla każdego równania podaj typ (ZR, J, L, B)
  1. \(y' = \frac{y^2 + xy}{x^2}\)
  2. \(y' + 3y = e^{7x}\)
  3. \(e^y(1+x^2)y' = 2x(1+e^y)\)
  4. \(y' - xy = y^3 e^{x^2}\)
  1. \(y' = \frac{(y/x)^2 + (y/x)}{1}\) — Jednorodne (zależy od \(y/x\))
  2. \(y' + 3y = e^{7x}\) — Liniowe niejednorodne (\(p(x) = 3\), \(q(x) = e^{7x}\))
  3. Przepisz: \(y' = \frac{2x(1+e^y)}{e^y(1+x^2)} = \frac{2x}{1+x^2}\cdot\frac{1+e^y}{e^y}\) — ZR (iloczyn \(g(x)\cdot h(y)\))
  4. \(y' - xy = e^{x^2}y^3\) — Bernoulli z \(r = 3\) (\(p(x) = -x\), \(q(x) = e^{x^2}\))

Twoja kolej: Zad. 4.2d

Rozwiąż zagadnienie początkowe
\[y' = \frac{1 + y^2}{1 + x^2}, \qquad y(0) = 1\]

Wskazówka: ZR. \(g(x) = \frac{1}{1+x^2}\), \(h(y) = 1+y^2\). Całka z \(\frac{1}{1+y^2}\) to \(\arctg y\).

Krok 1: Rozdziel i scałkuj

\[\frac{dy}{1+y^2} = \frac{dx}{1+x^2}\] \[\arctg y = \arctg x + C\]

Krok 2: Warunek początkowy

\[y(0) = 1: \quad \arctg 1 = \arctg 0 + C \implies \frac{\pi}{4} = 0 + C \implies C = \frac{\pi}{4}\] \[\arctg y = \arctg x + \frac{\pi}{4}\] \[\boxed{y = \tg\!\left(\arctg x + \frac{\pi}{4}\right)}\]

Można uprościć wzorem na \(\tg(\alpha+\beta)\): \(y = \frac{x + 1}{1 - x}\), ale postać z \(\tg\) jest wystarczająca.

Twoja kolej: Zad. 5.2a

Rozwiąż zagadnienie początkowe
\[\frac{dy}{dx} = \frac{y^2 + xy}{x^2}, \qquad y(1) = -1\]

Wskazówka: Jednorodne (z rozgrzewki). Podstaw \(u = y/x\). Po rozdzieleniu zmiennych dostaniesz \(\frac{du}{u^2} = \frac{dx}{x}\).

Podstawienie: \(y' = u^2 + u = g(u)\). Więc \(u'x + u = u^2 + u\), \(u'x = u^2\).

\[\frac{du}{u^2} = \frac{dx}{x} \implies -\frac{1}{u} = \ln|x| + C\]

Wróć do \(y\): \(u = y/x\), więc \(-\frac{x}{y} = \ln|x| + C\).

\[y = \frac{-x}{\ln|x| + C}\]

Warunek: \(y(1) = -1\): \(-1 = \frac{-1}{\ln 1 + C} = \frac{-1}{C}\), więc \(C = 1\).

\[\boxed{y = \frac{-x}{\ln x + 1}}\]
