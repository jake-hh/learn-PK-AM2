RR I rzędu — metoda czynnika całkującego

Egzamin Zad. 5 Praktyka  &sstrok; ~35 min

Z L09 wiesz, że równanie liniowe to \(y' + p(x)y = q(x)\). Teraz uczysz się je rozwiązywać metodą uzmienniania stałej (variation of constants). To najważniejsza metoda na egzaminie — Zad. 5 to prawie zawsze równanie liniowe lub sprowadzalne do liniowego.

Segment 1: Metoda uzmienniania stałej

Idea

Rozwiązujesz w dwóch krokach:

  1. Znajdź rozwiązanie jednorodnego (\(q = 0\)) — to proste ZR
  2. W rozwiązaniu jednorodnym zamień stałą \(C\) na funkcję \(C(x)\) i wyznacz ją
  1. Zapisz w postaci standardowej: \(y' + p(x)y = q(x)\)
  2. Rozwiąż jednorodne \(y' + p(x)y = 0\): \[\frac{dy}{y} = -p(x)\,dx \implies y_J = Ce^{-\int p(x)\,dx}\]
  3. Uzmienniaj: przyjmij \(y = C(x)\cdot e^{-\int p(x)\,dx}\), oblicz \(y'\): \[y' = C'(x)\,e^{-\int p\,dx} + C(x)\cdot(-p)\,e^{-\int p\,dx}\]
  4. Wstaw do pełnego równania. Człony z \(C(x)\) się skracają! Zostaje: \[C'(x)\,e^{-\int p\,dx} = q(x) \implies C'(x) = q(x)\,e^{\int p\,dx}\]
  5. Scałkuj \(C'(x)\) i wstaw z powrotem
Wzór końcowy  [WYKŁAD RR I rz.]
\[\boxed{y(x) = e^{-\int p(x)\,dx}\left(\int q(x)\,e^{\int p(x)\,dx}\,dx + C\right)}\]

Nie wkuwaj wzoru! Lepiej zapamiętać procedurę 5-krokową — jest mniej podatna na błędy.

Przykład rozwiązany: \(y' + \frac{2y}{x} = \frac{e^x}{x}\)  (Zad. 6.1a)

Krok 1 — Identyfikacja

Już w postaci standardowej: \(p(x) = \frac{2}{x}\), \(q(x) = \frac{e^x}{x}\).

Krok 2 — Rozwiązanie jednorodne
\[\frac{dy}{y} = -\frac{2}{x}\,dx \implies \ln|y| = -2\ln|x| + C_1 \implies y_J = \frac{C}{x^2}\]
Krok 3–4 — Uzmiennianie

Przyjmij \(y = \frac{C(x)}{x^2}\). Oblicz \(y'\):

\[y' = \frac{C'(x)}{x^2} - \frac{2C(x)}{x^3}\]

Wstaw do równania \(y' + \frac{2y}{x} = \frac{e^x}{x}\):

\[\frac{C'}{x^2} \cancel{- \frac{2C}{x^3}} + \cancel{\frac{2C}{x^3}} = \frac{e^x}{x}\]

Człony z \(C\) się skróciły (zawsze tak jest!). Zostaje:

\[C'(x) = \frac{e^x}{x}\cdot x^2 = xe^x\]
Krok 5 — Scałkuj \(C'(x) = xe^x\)

Przez części: \(\int xe^x\,dx = xe^x - e^x + C_0 = e^x(x-1) + C_0\).

Rozwiązanie ogólne:

\[y = \frac{e^x(x-1) + C_0}{x^2} = \boxed{\frac{(x-1)e^x}{x^2} + \frac{C}{x^2}}\]

Rozgrzewka: \(y' + 3y = e^{7x}\)  (Zad. 6.2a)

Rozwiąż

\(p(x) = 3\), \(q(x) = e^{7x}\). Stałe współczynniki — najłatwiejszy przypadek.

Wskazówka: Jednorodne: \(y_J = Ce^{-3x}\). Uzmienniaj: \(C'(x) = e^{7x}\cdot e^{3x} = e^{10x}\).

Jednorodne: \(y' + 3y = 0 \implies y_J = Ce^{-3x}\).

Uzmiennianie: \(y = C(x)e^{-3x}\), \(y' = C'e^{-3x} - 3Ce^{-3x}\).

Wstawiamy: \(C'e^{-3x} = e^{7x}\), więc \(C'(x) = e^{10x}\).

\[C(x) = \frac{e^{10x}}{10} + C_0\] \[y = \left(\frac{e^{10x}}{10} + C\right)e^{-3x} = \boxed{\frac{e^{7x}}{10} + Ce^{-3x}}\]

Przykład rozwiązany: \(y'\cos x - y\sin x = \sin 2x\)  (Zad. 6.1b)

Krok 1 — Postać standardowa

Dzielimy przez \(\cos x\):

\[y' - y\tg x = \frac{\sin 2x}{\cos x} = \frac{2\sin x\cos x}{\cos x} = 2\sin x\]

\(p(x) = -\tg x\), \(q(x) = 2\sin x\).

Krok 2 — Jednorodne
\[\frac{dy}{y} = \tg x\,dx \implies \ln|y| = -\ln|\cos x| + C_1 \implies y_J = \frac{C}{\cos x}\]
Krok 3–5 — Uzmiennianie

\(y = \frac{C(x)}{\cos x}\). Skracanie daje:

\[\frac{C'(x)}{\cos x} = 2\sin x \implies C'(x) = 2\sin x\cos x = \sin 2x\] \[C(x) = -\frac{\cos 2x}{2} + C_0\] \[y = \frac{1}{\cos x}\left(-\frac{\cos 2x}{2} + C\right) = \boxed{\frac{C - \frac{\cos 2x}{2}}{\cos x}}\]

Można uprościć: \(\cos 2x = 2\cos^2 x - 1\), więc \(y = \frac{C}{\cos x} - \cos x + \frac{1}{2\cos x}\). Ale na egzaminie powyższa postać wystarczy.

Twoja kolej: \(\frac{dy}{dx} + \frac{x}{1+x^2}\,y = \frac{1}{2x(1+x^2)}\)  (Zad. 6.1d)

Znajdź rozwiązanie ogólne

Wskazówka: \(p(x) = \frac{x}{1+x^2}\). Żeby scałkować \(p\), podstaw \(t = 1+x^2\).

Krok 1: Jednorodne

\[\int p(x)\,dx = \int\frac{x}{1+x^2}\,dx = \frac{1}{2}\ln(1+x^2)\] \[y_J = Ce^{-\frac{1}{2}\ln(1+x^2)} = \frac{C}{\sqrt{1+x^2}}\]

Krok 2: Uzmiennianie — wyznacz \(C'(x)\)

\(y = \frac{C(x)}{\sqrt{1+x^2}}\). Po skróceniu:

\[C'(x) = q(x)\cdot e^{\int p\,dx} = \frac{1}{2x(1+x^2)}\cdot\sqrt{1+x^2} = \frac{1}{2x\sqrt{1+x^2}}\]

Krok 3: Scałkuj \(C'(x)\)

Podstawienie: \(x = \tg\theta\), \(dx = \frac{d\theta}{\cos^2\theta}\), \(\sqrt{1+x^2} = \frac{1}{\cos\theta}\):

\[\int\frac{1}{2\tg\theta\cdot\frac{1}{\cos\theta}}\cdot\frac{d\theta}{\cos^2\theta} = \int\frac{\cos\theta}{2\tg\theta\cos^2\theta}\,d\theta = \int\frac{1}{2\sin\theta}\,d\theta\]

Albo prościej: podstaw \(u = \sqrt{1+x^2}\), \(u^2 = 1+x^2\), \(2u\,du = 2x\,dx\), \(x\,dx = u\,du\), \(x^2 = u^2 - 1\):

\[\int\frac{1}{2x\sqrt{1+x^2}}\,dx = \int\frac{u\,du}{2x^2\cdot u} = \int\frac{du}{2(u^2-1)} = \frac{1}{4}\ln\left|\frac{u-1}{u+1}\right| + C_0\]

Wracamy: \(u = \sqrt{1+x^2}\):

\[C(x) = \frac{1}{4}\ln\frac{\sqrt{1+x^2}-1}{\sqrt{1+x^2}+1} + C_0\] \[\boxed{y = \frac{1}{\sqrt{1+x^2}}\left(\frac{1}{4}\ln\frac{\sqrt{1+x^2}-1}{\sqrt{1+x^2}+1} + C\right)}\]

Bonus: Bernoulli — sprowadzanie do liniowego

Przepis

\(y' + p(x)y = q(x)y^r\). Podstaw \(z = y^{1-r}\), dostaniesz liniowe na \(z\).

Przykład: \(y' - xy = y^3 e^{x^2}\)  (Zad. 7.2a)

Rozwiązanie

\(r = 3\), \(p(x) = -x\), \(q(x) = e^{x^2}\). Podstawienie \(z = y^{1-3} = y^{-2}\).

\(z' = -2y^{-3}y'\). Dzielimy oryginalne równanie przez \(y^3\):

\[y^{-3}y' - xy^{-2} = e^{x^2}\] \[-\frac{1}{2}z' - xz = e^{x^2}\] \[z' + 2xz = -2e^{x^2}\]

To liniowe! \(p(x) = 2x\), \(q(x) = -2e^{x^2}\).

Jednorodne: \(z_J = Ce^{-x^2}\).

Uzmiennianie: \(C'(x) = -2e^{x^2}\cdot e^{x^2} = -2e^{2x^2}\).

\(C(x) = -2\int e^{2x^2}\,dx + C_0\) — ta całka nie ma postaci elementarnej, więc zostawiamy w postaci całkowej:

\[z = e^{-x^2}\left(-2\int e^{2x^2}\,dx + C\right)\]

Wracamy: \(y^{-2} = z\), więc \(y^2 = 1/z\).

Na egzaminie: jeśli całka nie wychodzi elementarnie, zostaw ją — to jest pełna odpowiedź.

Quiz

Sprawdź zrozumienie metody

0 / 3
W metodzie uzmienniania stałej dla \(y' + p(x)y = q(x)\), po wstawieniu \(y = C(x)e^{-\int p\,dx}\) do równania, człony z \(C(x)\) (bez pochodnej) się skracają. Dlaczego?
Bo \(C(x)\) jest dowolną funkcją różniczkowalną
Bo \(e^{-\int p\,dx}\) jest rozwiązaniem jednorodnego, więc spełnia \(y'+py=0\)
Bo \(p(x)\) i \(q(x)\) są niezależne od \(y\)
Bo pochodna \(e^{-\int p\,dx}\) wynosi zero
Cały sens metody: \(e^{-\int p\,dx}\) spełnia jednorodne, więc \(C(x)\cdot[\text{jednorodne}] = 0\). Zostaje tylko \(C'(x)\cdot e^{-\int p\,dx} = q(x)\).
Dla równania \(y' + 3y = e^{7x}\), rozwiązanie jednorodne to:
\(y_J = Ce^{-3x}\)
\(y_J = Ce^{3x}\)
\(y_J = Ce^{7x}\)
\(y_J = Ce^{-7x}\)
\(y' + 3y = 0\): \(\frac{dy}{y} = -3\,dx\), \(\ln|y| = -3x + C_1\), \(y = Ce^{-3x}\). Znak minus z \(p(x) = 3\)!
Równanie Bernoulliego \(y' + py = qy^r\) sprowadzamy do liniowego podstawieniem:
\(z = y^r\)
\(z = y/x\)
\(z = y^{1-r}\)
\(z = \ln y\)
\(z = y^{1-r}\) eliminuje nieliniowość. Np. dla \(r=3\): \(z = y^{-2}\), co daje liniowe na \(z\).
