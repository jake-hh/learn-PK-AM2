RR II rzędu niejednorodne — metoda przewidywanych współczynników

Egzamin Zad. 6 Praktyka  ⏱ ~40 min

Masz już \(y_J\) z L12. Teraz szukamy \(y_s\) — jednego rozwiązania szczególnego niejednorodnego \(y'' + py' + qy = h(x)\). Metoda: zgadujemy postać \(y_s\) na podstawie \(h(x)\), a potem wyznaczamy współczynniki.

Segment 1: Zasada MWN

Idea

Jeśli \(h(x)\) jest wielomianem, eksponentą, sinusem/cosinusem lub ich kombinacją, to \(y_s\) ma tę samą postać — z nieznanymi współczynnikami, które wyznaczamy przez podstawienie.

Jedyny haczyk: jeśli nasza „zgadywanka” jest już rozwiązaniem jednorodnego, mnożymy przez \(x\) (lub \(x^2\)).

Tabelka MWN  [WYKŁAD RR II rzędu]

Równanie char.: \(\lambda^2 + p\lambda + q = 0\). Niech \(s\) = krotność „problematycznego” pierwiastka.

\(h(x)\)Postać \(y_s\)Kiedy \(s > 0\)?
\(W_n(x)\) (wielomian st. \(n\)) \(x^s \cdot V_n(x)\) \(s\) = krotność \(\lambda = 0\)
\(e^{\alpha x} W_n(x)\) \(x^s \cdot e^{\alpha x} V_n(x)\) \(s\) = krotność \(\lambda = \alpha\)
\(a\cos\beta x + b\sin\beta x\) \(x^s(A\cos\beta x + B\sin\beta x)\) \(s = 1\) jeśli \(i\beta\) jest pierw.; inaczej \(s = 0\)
\(e^{\alpha x}(a\cos\beta x + b\sin\beta x)\) \(x^s \cdot e^{\alpha x}(A\cos\beta x + B\sin\beta x)\) \(s = 1\) jeśli \(\alpha + i\beta\) jest pierw.; inaczej \(s = 0\)

\(V_n(x)\) = wielomian stopnia \(n\) z nowymi, nieznanymi współczynnikami.

Zasada superpozycji

Jeśli \(h(x) = h_1(x) + h_2(x)\), to \(y_s = y_{s_1} + y_{s_2}\) — rozwiązujemy osobno dla każdego składnika i dodajemy.

Algorytm: pełne RR II rzędu niejednorodne (MWN)

  1. Rozwiąż jednorodne → \(y_J = C_1 y_1 + C_2 y_2\) (L12)
  2. Sprawdź postać \(h(x)\) i odczytaj z tabelki postać \(y_s\)
  3. Sprawdź czy trzeba mnożyć przez \(x^s\) (porównaj z pierwiastkami char.)
  4. Podstaw \(y_s\) do równania, oblicz \(y_s'\) i \(y_s''\), przyrównaj współczynniki
  5. Zapisz \(y = y_J + y_s\)

Przykład rozwiązany: \(y'' + 2y = x^2 + 2\)  (Zad. 2.2b)

Rozwiązanie

Jednorodne: \(\lambda^2 + 2 = 0 \implies \lambda = \pm i\sqrt{2}\). Przypadek 3:

\[y_J = C_1 \cos\sqrt{2}\,x + C_2 \sin\sqrt{2}\,x\]

MWN: \(h(x) = x^2 + 2\) (wielomian st. 2). \(\lambda = 0\) nie jest pierwiastkiem char. ⇒ \(s = 0\).

Postać: \(y_s = Ax^2 + Bx + C\).

Pochodne: \(y_s' = 2Ax + B\), \(y_s'' = 2A\).

Podstawienie:

\[2A + 2(Ax^2 + Bx + C) = x^2 + 2\] \[2Ax^2 + 2Bx + (2A + 2C) = x^2 + 2\]

Porównanie współczynników:

\[x^2:\; 2A = 1 \implies A = \tfrac{1}{2}\] \[x^1:\; 2B = 0 \implies B = 0\] \[x^0:\; 2A + 2C = 2 \implies 1 + 2C = 2 \implies C = \tfrac{1}{2}\]

Wynik:

\[\boxed{y = C_1 \cos\sqrt{2}\,x + C_2 \sin\sqrt{2}\,x + \frac{x^2 + 1}{2}}\]

Przykład rozwiązany: \(y'' - 3y' + 2y = e^x\)  (Zad. 2.2a)

Rozwiązanie — uwaga na rezonans!

Jednorodne: \(\lambda^2 - 3\lambda + 2 = (\lambda-1)(\lambda-2) = 0 \implies \lambda_1 = 1,\; \lambda_2 = 2\).

\[y_J = C_1 e^x + C_2 e^{2x}\]

MWN: \(h(x) = e^x\), czyli \(\alpha = 1\). Ale \(\alpha = 1\) jest pierwiastkiem char. (krotność \(s = 1\))!

Postać: \(y_s = Ax \cdot e^x\) (mnożymy przez \(x^1\)).

Pochodne:

\[y_s' = Ae^x + Axe^x = Ae^x(1 + x)\] \[y_s'' = Ae^x(2 + x)\]

Podstawienie:

\[Ae^x(2+x) - 3Ae^x(1+x) + 2Axe^x = e^x\] \[Ae^x\bigl[(2+x) - 3(1+x) + 2x\bigr] = e^x\] \[Ae^x(2 + x - 3 - 3x + 2x) = e^x\] \[Ae^x(-1) = e^x \implies A = -1\]

Wynik:

\[\boxed{y = C_1 e^x + C_2 e^{2x} - xe^x}\]

Twoja kolej: \(y'' - 5y' + 6y = 13\sin 3x\)  (z wykładu)

Sinusy i cosinusy

Pierw. char.: \(\lambda = 2, 3\). \(i\beta = 3i\) nie jest pierw. ⇒ \(s = 0\). Postać: \(y_s = A\sin 3x + B\cos 3x\).

Krok 1: Jednorodne

\[\lambda^2 - 5\lambda + 6 = (\lambda-2)(\lambda-3) = 0\] \[y_J = C_1 e^{2x} + C_2 e^{3x}\]

Krok 2: Podstawienie \(y_s = A\sin 3x + B\cos 3x\)

\(y_s' = 3A\cos 3x - 3B\sin 3x\), \(\;y_s'' = -9A\sin 3x - 9B\cos 3x\).

Podstawiamy do \(y'' - 5y' + 6y = 13\sin 3x\):

\[\sin 3x:\; -9A + 15B + 6A = 13 \implies -3A + 15B = 13\] \[\cos 3x:\; -9B - 15A + 6B = 0 \implies -15A - 3B = 0\]

Z drugiego: \(B = -5A\). Wstawiamy: \(-3A - 75A = 13 \implies A = -\frac{13}{78} = -\frac{1}{6}\).

\(B = 5/6\).

Krok 3: Wynik

\[\boxed{y = C_1 e^{2x} + C_2 e^{3x} - \frac{\sin 3x}{6} + \frac{5\cos 3x}{6}}\]

Twoja kolej: \(y'' - y = 2e^{2x}\)  (z wykładu)

Eksponenta bez rezonansu

\(\alpha = 2\). Pierw. char.: \(\lambda = \pm 1\). \(\alpha = 2\) nie jest pierw. ⇒ \(s = 0\). Postać: \(y_s = Ae^{2x}\).

\(y_J = C_1 e^x + C_2 e^{-x}\). Podstawiamy \(y_s = Ae^{2x}\):

\[4Ae^{2x} - Ae^{2x} = 2e^{2x} \implies 3A = 2 \implies A = \frac{2}{3}\] \[\boxed{y = C_1 e^x + C_2 e^{-x} + \frac{2}{3}e^{2x}}\]

Twoja kolej: \(y'' + 3y' + 2y = \sin 2x + 2\cos x\)  (Zad. 2.2e)

Superpozycja!

Rozwiąż osobno dla \(h_1 = \sin 2x\) i \(h_2 = 2\cos x\), potem dodaj.

Dlaczego rozdzielamy? \(\sin 2x\) ma \(\beta = 2\), a \(\cos x\) ma \(\beta = 1\) — to różne częstości! Rozdzielamy składniki superpozycji jeśli mają inne bety. Każdy dostaje swoją parę (sin + cos na tej samej częstości).

Pierw. char.: \(\lambda = -1, -2\). Żadne \(i\beta\) nie jest pierw. ⇒ \(s = 0\) w obu.

Jednorodne + postać \(y_{s_1}\) i \(y_{s_2}\)

\[y_J = C_1 e^{-x} + C_2 e^{-2x}\]

\(y_{s_1} = A\sin 2x + B\cos 2x\), \(\;y_{s_2} = D\sin x + E\cos x\).

Współczynniki dla \(\sin 2x\)

Podstawiamy \(y_{s_1}\):

\[\sin 2x:\; -4A - 6B + 2A = 1 \implies -2A - 6B = 1\] \[\cos 2x:\; -4B + 6A + 2B = 0 \implies 6A - 2B = 0 \implies B = 3A\]

\(-2A - 18A = 1 \implies A = -1/20\), \(B = -3/20\).

Współczynniki dla \(2\cos x\)

Podstawiamy \(y_{s_2}\):

\[\sin x:\; -D - 3E + 2D = 0 \implies D - 3E = 0\] \[\cos x:\; -E + 3D + 2E = 2 \implies 3D + E = 2\]

\(D = 3E\), \(9E + E = 2 \implies E = 1/5\), \(D = 3/5\).

Wynik

\[\boxed{y = C_1 e^{-x} + C_2 e^{-2x} - \frac{\sin 2x + 3\cos 2x}{20} + \frac{3\sin x + \cos x}{5}}\]

Twoja kolej: \(y'' + 4y = x\sin 2x\)  (Zad. 2.2c)

Rezonans trygonometryczny!

\(h(x) = x\sin 2x\). \(\lambda = \pm 2i\) — \(i\beta = 2i\) jest pierw. char.! \(s = 1\).

Postać: \(y_s = x\bigl[(Ax+B)\sin 2x + (Cx+D)\cos 2x\bigr]\).

To dużo rachunków — ale na egzaminie tak trudne raczej nie padnie. Ważne: rozumiesz jak wybrać postać.

\(y_J = C_1\cos 2x + C_2\sin 2x\).

Rozwijamy \(y_s = (Ax^2+Bx)\sin 2x + (Cx^2+Dx)\cos 2x\) i obliczamy \(y_s'', y_s'\).

Po podstawieniu i porównaniu (pomijam rachunki):

\[A = 0,\quad B = -\frac{1}{8},\quad C = -\frac{1}{16},\quad D = 0\] \[\boxed{y = C_1\cos 2x + C_2\sin 2x - \frac{x\sin 2x}{8} - \frac{x^2\cos 2x}{16}}\]

Sprawdzenie: podstaw \(y_s\) do równania i zweryfikuj, że dostaniesz \(x\sin 2x\).
