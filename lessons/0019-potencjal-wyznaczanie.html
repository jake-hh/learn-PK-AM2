Pole potencjalne — wyznaczanie potencjału

Egzamin teoria + praktyka Teoria+Praktyka  ⏱ ~35 min

Lekcja 17 wprowadziła pojęcie pola potencjalnego. Tu ćwiczymy technikę wyznaczania potencjału — algorytm „całkuj-zróżniczkuj” i jego zastosowanie do liczenia całek krzywoliniowych.

Segment 1: Algorytm „całkuj-zróżniczkuj”

Metoda wyznaczania potencjału  [WYKŁAD]

Dane pole \(\vec{F} = (P, Q)\). Szukamy \(U(x,y)\) takiego, że \(\nabla U = \vec{F}\).

  1. Sprawdź warunek konieczny: \(\dfrac{\partial Q}{\partial x} = \dfrac{\partial P}{\partial y}\)
  2. Całkuj \(P\) po \(x\): \(U(x,y) = \displaystyle\int P(x,y)\,dx + \varphi(y)\)
    \(\varphi(y)\) — „stała” całkowania, funkcja tylko \(y\)
  3. Zróżniczkuj \(U\) po \(y\): \(\dfrac{\partial U}{\partial y} = \dfrac{\partial}{\partial y}\!\left[\int P\,dx\right] + \varphi'(y)\)
  4. Porównaj z \(Q\): przyrównaj do \(Q(x,y)\) i wyznacz \(\varphi'(y)\)
  5. Scałkuj \(\varphi'(y)\): otrzymujesz \(U(x,y) + C\)
Dlaczego to działa?

Szukamy \(U\) spełniającego \(\partial U/\partial x = P\) i \(\partial U/\partial y = Q\). Z pierwszego warunku: \(U = \int P\,dx + \varphi(y)\). Drugi warunek wyznacza \(\varphi(y)\).

Kluczowy moment: \(\varphi'(y)\) musi zależeć tylko od \(y\) (nie od \(x\)). Jeśli tak nie jest, pole nie jest potencjalne — ale to już wykluczyliśmy w kroku 1.

Alternatywa — całka po łamanej

Zamiast „całkuj-zróżniczkuj” możesz policzyć potencjał wprost:

\[U(x,y) = \int_{x_0}^{x} P(t, y_0)\,dt + \int_{y_0}^{y} Q(x, s)\,ds\]

Zwykle bierz \((x_0, y_0) = (0,0)\), jeśli leży w dziedzinie.

Przykład 1: \(\vec{F} = (2xy + 3,\; x^2 - 2y)\)

Rozwiązanie

Krok 1 — warunek: \(P = 2xy + 3\), \(Q = x^2 - 2y\).

\[\frac{\partial Q}{\partial x} = 2x, \quad \frac{\partial P}{\partial y} = 2x \quad \checkmark\]

Krok 2 — całkuj \(P\) po \(x\):

\[U = \int (2xy + 3)\,dx = x^2 y + 3x + \varphi(y)\]

Krok 3 — zróżniczkuj po \(y\):

\[\frac{\partial U}{\partial y} = x^2 + \varphi'(y)\]

Krok 4 — porównaj z \(Q\):

\[x^2 + \varphi'(y) = x^2 - 2y \implies \varphi'(y) = -2y\]

Krok 5 — scałkuj: \(\varphi(y) = -y^2 + C\).

\[\boxed{U(x,y) = x^2 y + 3x - y^2 + C}\]

Weryfikacja: \(\partial U/\partial x = 2xy + 3 = P\;\checkmark\), \(\partial U/\partial y = x^2 - 2y = Q\;\checkmark\)

Przykład 2: \(\vec{F} = (e^x \sin y + y,\; e^x \cos y + x + 1)\)

Rozwiązanie

Warunek: \(\partial Q/\partial x = e^x \cos y + 1 = \partial P/\partial y\;\checkmark\)

Całkuj \(P\) po \(x\):

\[U = \int (e^x \sin y + y)\,dx = e^x \sin y + xy + \varphi(y)\]

Zróżniczkuj po \(y\) i porównaj z \(Q\):

\[\frac{\partial U}{\partial y} = e^x \cos y + x + \varphi'(y) = e^x \cos y + x + 1\] \[\varphi'(y) = 1 \implies \varphi(y) = y + C\] \[\boxed{U(x,y) = e^x \sin y + xy + y + C}\]

Twoja kolej 1: \(\vec{F} = \bigl(y\cos(xy) + 1,\; x\cos(xy)\bigr)\)

Wyznacz potencjał

Zastosuj algorytm „całkuj-zróżniczkuj”.

Krok 1: Warunek

\[\frac{\partial Q}{\partial x} = \cos(xy) - xy\sin(xy)\] \[\frac{\partial P}{\partial y} = \cos(xy) - xy\sin(xy) \quad \checkmark\]

Krok 2: Całkowanie i wyznaczenie \(\varphi\)

\[U = \int \bigl(y\cos(xy) + 1\bigr)\,dx = \sin(xy) + x + \varphi(y)\]

(bo \(\int y\cos(xy)\,dx = \sin(xy)\) — \(y\) jest „stałą” przy całkowaniu po \(x\))

Krok 3: Porównanie z \(Q\)

\[\frac{\partial U}{\partial y} = x\cos(xy) + \varphi'(y) = Q = x\cos(xy)\] \[\varphi'(y) = 0 \implies \varphi = C\] \[\boxed{U(x,y) = \sin(xy) + x + C}\]

Twoja kolej 2: Całka w polu potencjalnym

Oblicz

\[\int_\Gamma \left(\frac{2x}{y^2} + 1\right)dx - \frac{2x^2}{y^3}\,dy, \qquad A(1,1) \to B(2,3)\]

Wskazówka: sprawdź potencjalność, wyznacz \(U\), użyj \(U(B) - U(A)\).

Krok 1: Sprawdź warunek

\(P = \dfrac{2x}{y^2} + 1\), \(Q = -\dfrac{2x^2}{y^3}\).

\[\frac{\partial Q}{\partial x} = -\frac{4x}{y^3}, \quad \frac{\partial P}{\partial y} = -\frac{4x}{y^3} \quad \checkmark\]

Krok 2: Wyznacz potencjał

\[U = \int \left(\frac{2x}{y^2} + 1\right)dx = \frac{x^2}{y^2} + x + \varphi(y)\] \[\frac{\partial U}{\partial y} = -\frac{2x^2}{y^3} + \varphi'(y) = -\frac{2x^2}{y^3} \implies \varphi'(y) = 0\] \[U(x,y) = \frac{x^2}{y^2} + x\]

Krok 3: Wynik

\[U(B) - U(A) = U(2,3) - U(1,1) = \left(\frac{4}{9} + 2\right) - \left(1 + 1\right) = \frac{4}{9} + 2 - 2 = \boxed{\frac{4}{9}}\]

Twoja kolej 3: Potencjał w \(\mathbb{R}^3\)

Wyznacz potencjał

\(\vec{F} = (yz,\; xz,\; xy)\). Algorytm ten sam, ale \(\varphi\) zależy od \(y\) i \(z\).

Krok 1: Sprawdź warunki (3 pary)

\(P = yz\), \(Q = xz\), \(R = xy\).

\[\frac{\partial R}{\partial y} = x = \frac{\partial Q}{\partial z} \;\checkmark \qquad \frac{\partial P}{\partial z} = y = \frac{\partial R}{\partial x} \;\checkmark \qquad \frac{\partial Q}{\partial x} = z = \frac{\partial P}{\partial y} \;\checkmark\]

Krok 2: Całkuj \(P\) po \(x\)

\[U = \int yz\,dx = xyz + \varphi(y,z)\]

Krok 3: Wyznacz \(\varphi\)

Zróżniczkuj po \(y\):

\[\frac{\partial U}{\partial y} = xz + \frac{\partial \varphi}{\partial y} = Q = xz \implies \frac{\partial \varphi}{\partial y} = 0 \implies \varphi = \varphi(z)\]

Zróżniczkuj po \(z\):

\[\frac{\partial U}{\partial z} = xy + \varphi'(z) = R = xy \implies \varphi'(z) = 0 \implies \varphi = C\] \[\boxed{U(x,y,z) = xyz + C}\]

Fiszki

Algorytm wyznaczania potencjału (3 główne kroki)
  1. Całkuj \(P\) po \(x\): \(U = \int P\,dx + \varphi(y)\)
  2. Zróżniczkuj po \(y\), porównaj z \(Q\) → wyznacz \(\varphi'(y)\)
  3. Scałkuj \(\varphi'(y)\) → gotowy \(U(x,y) + C\)
