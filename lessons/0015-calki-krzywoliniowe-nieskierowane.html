Segment 1: Parametryzacja krzywych

Kluczowa umiejętność

Całka krzywoliniowa sprowadza się do całki po parametrze \(t\). Musisz umieć sparametryzować krzywą!

Segment 2: Wzór obliczeniowy

Wzór — Całka krzywoliniowa nieskierowana  [WYKŁAD]

Dla łuku \(\Gamma\) sparametryzowanego \((x(t), y(t))\), \(t \in [\alpha, \beta]\):

\[\boxed{\int_\Gamma f(x,y)\,dl = \int_\alpha^\beta f\bigl(x(t),\, y(t)\bigr)\,\sqrt{[x'(t)]^2 + [y'(t)]^2}\;\,dt}\]

W \(\mathbb{R}^3\) dodajemy \([z'(t)]^2\) pod pierwiastkiem.

Element łuku dl to długość infinitezymalnego kawałka krzywej — przyprostokątne = dx i dy.
Specjalny przypadek: wykres \(y = g(x)\)

Parametryzacja \(x = t\), \(y = g(t)\), więc \(x' = 1\), \(y' = g'\):

\[\int_\Gamma f\,dl = \int_a^b f(x,\, g(x))\,\sqrt{1 + [g'(x)]^2}\;\,dx\]

Algorytm

  1. Sparametryzuj krzywą: \(x(t), y(t)\), granice \(t \in [\alpha, \beta]\)
  2. Oblicz \(x'(t)\) i \(y'(t)\)
  3. Oblicz \(dl = \sqrt{x'^2 + y'^2}\,dt\)
  4. Wstaw wszystko do \(\int_\alpha^\beta f(x(t),y(t)) \cdot dl\) i policz całkę

Przykład rozwiązany: \(\int_\Gamma (4\sqrt{3}\,x - \sqrt{3}\,y)\,dl\) po prostej \(EH\)  (Zad. 1a.i)

Rozwiązanie

Krzywa: prosta od \(E(-1, 0)\) do \(H(0, 1)\).

Parametryzacja: \(x = -1 + t\), \(y = t\), \(t \in [0, 1]\).

\(x' = 1\), \(y' = 1\), \(\sqrt{x'^2 + y'^2} = \sqrt{2}\).

Całka:

\[\int_0^1 \bigl(4\sqrt{3}(-1+t) - \sqrt{3}\,t\bigr)\sqrt{2}\,dt = \sqrt{6}\int_0^1 (-4 + 4t - t)\,dt\] \[= \sqrt{6}\int_0^1 (-4 + 3t)\,dt = \sqrt{6}\left[-4t + \frac{3t^2}{2}\right]_0^1 = \sqrt{6}\left(-4 + \frac{3}{2}\right) = -\frac{5\sqrt{6}}{2}\]

Przykład rozwiązany: \(\int_C (x^2+y^2+z^2)\,dl\), linia śrubowa  (Zad. 1d)

Rozwiązanie

Parametryzacja: \(x = a\cos t\), \(y = a\sin t\), \(z = bt\), \(t \in [0, 2\pi]\).

\(x' = -a\sin t\), \(y' = a\cos t\), \(z' = b\).

\[\sqrt{x'^2 + y'^2 + z'^2} = \sqrt{a^2 + b^2}\]

Funkcja pod całką: \(x^2 + y^2 + z^2 = a^2 + b^2 t^2\).

Całka:

\[\sqrt{a^2+b^2}\int_0^{2\pi} (a^2 + b^2 t^2)\,dt = \sqrt{a^2+b^2}\left[a^2 t + \frac{b^2 t^3}{3}\right]_0^{2\pi}\] \[= \sqrt{a^2+b^2}\left(2\pi a^2 + \frac{8\pi^3 b^2}{3}\right) = \boxed{2\pi\sqrt{a^2+b^2}\left(a^2 + \frac{4\pi^2 b^2}{3}\right)}\]

Twoja kolej: \(\int_C (x^{4/3}+y^{4/3})\,dl\), asteroida  (Zad. 1b)

Rozwiąż samodzielnie

Asteroida: \(x = a\cos^3 t\), \(y = a\sin^3 t\), \(t \in [0, 2\pi]\).

Wskazówka: \(x' = -3a\cos^2 t\sin t\), \(y' = 3a\sin^2 t\cos t\). Uprość \(\sqrt{x'^2+y'^2}\). Użyj symetrii!

Krok 1: Element łuku \(dl\)

\[x'^2 + y'^2 = 9a^2\cos^4 t\sin^2 t + 9a^2\sin^4 t\cos^2 t = 9a^2\cos^2 t\sin^2 t\] \[\sqrt{x'^2 + y'^2} = 3a|\sin t\cos t| = \frac{3a}{2}|\sin 2t|\]

Krok 2: Funkcja pod całką

\[x^{4/3} + y^{4/3} = a^{4/3}\cos^4 t + a^{4/3}\sin^4 t = a^{4/3}(\cos^4 t + \sin^4 t)\]

Uprośćmy: \(\cos^4 t + \sin^4 t = 1 - 2\sin^2 t\cos^2 t = 1 - \frac{\sin^2 2t}{2}\).

Krok 3: Całkowanie (z symetrią)

Symetria: \(|\sin 2t|\) i \(\cos^4 t + \sin^4 t\) mają okres \(\pi/2\). Liczymy \(\int_0^{\pi/2}\) i mnożymy ×4.

\[I = 4 \cdot \frac{3a}{2} \cdot a^{4/3}\int_0^{\pi/2}\!\left(1 - \frac{\sin^2 2t}{2}\right)\sin 2t\,dt\]

Podstawienie \(u = \cos 2t\), \(du = -2\sin 2t\,dt\):

\[= 6a^{7/3}\int_0^{\pi/2}\!\left(\sin 2t - \frac{\sin^3 2t}{2}\right)dt\] \[\int_0^{\pi/2}\sin 2t\,dt = 1, \qquad \int_0^{\pi/2}\sin^3 2t\,dt = \frac{2}{3}\] \[= 6a^{7/3}\!\left(1 - \frac{1}{3}\right) = \boxed{4a^{7/3}}\]

Twoja kolej: długość kardioidy  (Zad. 2b)

Zastosowanie: długość = \(\int_\Gamma dl\)

Kardioida: \(x = 2a\cos t - a\cos 2t\), \(y = 2a\sin t - a\sin 2t\), \(t \in [0, 2\pi]\).

Wskazówka: uprość \(x'^2 + y'^2\). Użyj \(\cos\alpha - \cos\beta\) i wzorów redukcyjnych.

Pochodne:

\[x' = -2a\sin t + 2a\sin 2t, \qquad y' = 2a\cos t - 2a\cos 2t\]

Suma kwadratów:

\[x'^2 + y'^2 = 4a^2\bigl[(\sin t - \sin 2t)^2 + (\cos t - \cos 2t)^2\bigr]\] \[= 4a^2\bigl[\sin^2 t - 2\sin t\sin 2t + \sin^2 2t + \cos^2 t - 2\cos t\cos 2t + \cos^2 2t\bigr]\] \[= 4a^2\bigl[2 - 2(\cos t\cos 2t + \sin t\sin 2t)\bigr] = 4a^2\bigl[2 - 2\cos t\bigr]\] \[= 8a^2(1 - \cos t) = 16a^2\sin^2\frac{t}{2}\]

\(\sqrt{x'^2+y'^2} = 4a\left|\sin\frac{t}{2}\right| = 4a\sin\frac{t}{2}\) (bo \(t \in [0, 2\pi]\)).

Długość:

\[L = \int_0^{2\pi} 4a\sin\frac{t}{2}\,dt = 4a\left[-2\cos\frac{t}{2}\right]_0^{2\pi} = 4a(-2(-1) + 2(1)) = \boxed{16a}\]
