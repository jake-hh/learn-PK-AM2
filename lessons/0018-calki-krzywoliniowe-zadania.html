Całki krzywoliniowe — zadania zbiorcze

Egzamin Zad. 4 Praktyka  ⏱ ~55 min

Lekcja czysto praktyczna — zbieramy wszystkie metody z lekcji 14–17 i ćwiczymy na zadaniach z list i egzaminów. Kluczowa umiejętność: szybko rozpoznać typ i dobrać metodę.

Strategia — co zrobić NAJPIERW

Przed każdym zadaniem z całką krzywoliniową skierowaną zadaj sobie 4 pytania:

  1. Nieskierowana (\(\mathrm{d}l\)) czy skierowana (\(\mathrm{d}x, \mathrm{d}y\))? — to widać od razu z zapisu.
  2. Krzywa zamknięta? Jeśli tak → rozważ tw. Greena (zamienia całkę krzywoliniową na podwójną).
  3. Krzywa otwarta? Sprawdź potencjalność: \(\frac{\partial Q}{\partial x} = \frac{\partial P}{\partial y}\)? Jeśli tak → \(\int_A^B = F(B) - F(A)\).
  4. Nic z powyższych? → Parametryzuj krzywą i licz wprost.

Zasada: Green > potencjał > parametryzacja (od najszybszego do najwolniejszego).

Przykład 1: Parametryzacja wprost  (Lista 6, Zad. 4a.iii)

Zadanie

Oblicz \(\displaystyle\int_\Gamma (xy - 1)\,\mathrm{d}x + x^2 y\,\mathrm{d}y\), gdzie \(\Gamma\) to łuk elipsy:

\[x(t) = \cos t, \quad y(t) = 2\sin t, \quad \text{od } A(1,0) \text{ do } B(0,2)\]

Krok 1: Wybór metody

Dlaczego parametryzacja? Krzywa otwarta, więc Green odpada. Sprawdzamy potencjalność:

\[P = xy - 1, \quad Q = x^2 y\] \[\frac{\partial Q}{\partial x} = 2xy, \qquad \frac{\partial P}{\partial y} = x\]

\(2xy \neq x\) — pole nie jest potencjalne. Pozostaje parametryzacja wprost.

Krok 2: Zakres parametru i pochodne

\(A(1,0)\): \(\cos t = 1,\; 2\sin t = 0 \Rightarrow t = 0\).

\(B(0,2)\): \(\cos t = 0,\; 2\sin t = 2 \Rightarrow t = \tfrac{\pi}{2}\).

Parametr \(t \in [0, \tfrac{\pi}{2}]\). Pochodne:

\[x'(t) = -\sin t, \qquad y'(t) = 2\cos t\]

Krok 3: Podstawienie i uproszczenie

Wyrażamy \(P\) i \(Q\) przez \(t\):

\[P = \cos t \cdot 2\sin t - 1 = \sin 2t - 1\] \[Q = \cos^2 t \cdot 2\sin t\]

Całka \(I = \int_0^{\pi/2} [P \cdot x' + Q \cdot y']\,\mathrm{d}t\):

\[I = \int_0^{\pi/2}\bigl[(\sin 2t - 1)(-\sin t) + 2\sin t \cos^2 t \cdot 2\cos t\bigr]\,\mathrm{d}t\]

Rozpisujemy poszczególne składniki:

\[-\sin t \cdot \sin 2t = -\sin t \cdot 2\sin t \cos t = -2\sin^2 t \cos t\] \[-(-\sin t) \cdot 1 = \sin t\] \[4\sin t \cos^3 t\]

Razem:

\[I = \int_0^{\pi/2}\bigl[-2\sin^2 t\cos t + \sin t + 4\sin t\cos^3 t\bigr]\,\mathrm{d}t\]

Krok 4: Obliczenie

Każdy składnik osobno (podstawienie \(u = \sin t\) lub \(u = \cos t\)):

\[\int_0^{\pi/2} -2\sin^2 t\cos t\,\mathrm{d}t = \left[-\frac{2\sin^3 t}{3}\right]_0^{\pi/2} = -\frac{2}{3}\] \[\int_0^{\pi/2} \sin t\,\mathrm{d}t = \bigl[-\cos t\bigr]_0^{\pi/2} = 0 - (-1) = 1\] \[\int_0^{\pi/2} 4\sin t\cos^3 t\,\mathrm{d}t = \left[-\cos^4 t\right]_0^{\pi/2} = 0 - (-1) = 1\]

Wynik:

\[\boxed{I = -\frac{2}{3} + 1 + 1 = \frac{4}{3}}\]

Przykład 2: Orientacja krzywej  (Lista 6, Zad. 4d)

Zadanie

Oblicz \(\displaystyle\int_L y^2\,\mathrm{d}x + x^2\,\mathrm{d}y\), gdzie \(L\) = górna połowa elipsy \(x = a\cos t,\; y = b\sin t\), orientacja zgodna z ruchem wskazówek zegara.

Krok 1: Ustalenie kierunku parametru

Dlaczego parametryzacja? Krzywa otwarta (pół-elipsa), potencjalność: \(\partial(x^2)/\partial x = 2x \neq \partial(y^2)/\partial y = 2y\). Liczymy wprost.

Orientacja: Standardowa parametryzacja \(t: 0 \to \pi\) daje ruch z \((a,0)\) do \((-a,0)\) — to kierunek przeciwny do wskazówek zegara (CCW).

Ruch zgodny z zegarem (CW) = odwrotnie ⇒ \(t: \pi \to 0\).

Zamiana granic daje znak minus przed całką:

\[I = \int_\pi^0 [\ldots]\,\mathrm{d}t = -\int_0^\pi [\ldots]\,\mathrm{d}t\]

Krok 2: Podstawienie

\(x = a\cos t,\; x' = -a\sin t,\; y = b\sin t,\; y' = b\cos t\).

\[I = -\int_0^\pi \bigl[b^2\sin^2 t \cdot (-a\sin t) + a^2\cos^2 t \cdot b\cos t\bigr]\,\mathrm{d}t\] \[= -\int_0^\pi \bigl[-ab^2\sin^3 t + a^2 b\cos^3 t\bigr]\,\mathrm{d}t\] \[= \int_0^\pi \bigl[ab^2\sin^3 t - a^2 b\cos^3 t\bigr]\,\mathrm{d}t\]

Krok 3: Obliczenie

Znane całki:

\[\int_0^\pi \sin^3 t\,\mathrm{d}t = \frac{4}{3}, \qquad \int_0^\pi \cos^3 t\,\mathrm{d}t = 0 \;\text{(symetria)}\]

Wynik:

\[\boxed{I = ab^2 \cdot \frac{4}{3} - 0 = \frac{4ab^2}{3}}\]

Twoja kolej 1: Green na okręgu  (Lista 6, Zad. 4e)

Zadanie

Oblicz \(\displaystyle\oint_C yx^2\,\mathrm{d}y - x^2\,\mathrm{d}x\), gdzie \(C\) = okrąg o promieniu \(a\), orientacja dodatnia (CCW).

Wskazówka: Krzywa zamknięta + orientacja dodatnia = idealny przypadek na Greena.

Krok 1: Identyfikacja i rotacja

Krzywa zamknięta, orientacja dodatnia ⇒ tw. Greena:

\[\oint_C P\,\mathrm{d}x + Q\,\mathrm{d}y = \iint_D \left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right)\mathrm{d}A\]

Identyfikacja: \(P = -x^2,\; Q = yx^2\).

\[\frac{\partial Q}{\partial x} = 2xy, \qquad \frac{\partial P}{\partial y} = 0\]

Rotacja: \(2xy - 0 = 2xy\).

Krok 2: Całka podwójna

Trzeba obliczyć \(\iint_D 2xy\,\mathrm{d}A\), gdzie \(D\) to koło \(x^2 + y^2 \leq a^2\).

Argument symetrii: Funkcja \(f(x,y) = 2xy\) jest nieparzysta względem \(x\) (tzn. \(f(-x,y) = -f(x,y)\)), a obszar \(D\) jest symetryczny względem osi \(y\).

Całka funkcji nieparzystej po obszarze symetrycznym = 0.

\[\boxed{\oint_C yx^2\,\mathrm{d}y - x^2\,\mathrm{d}x = 0}\]

Twoja kolej 2: Osobliwość w polu  (Lista 6, Zad. 7 — klasyk!)

Zadanie

Oblicz \(\displaystyle\oint_C \frac{x\,\mathrm{d}y - y\,\mathrm{d}x}{x^2 + y^2}\), gdzie \(C\) jest zamkniętą krzywą klasy \(C^1\) z orientacją dodatnią, obejmującą obszar \(S\).

Przypadek (a): \((0,0) \in S\)   Przypadek (b): \((0,0) \notin S\)

To klasyczne zadanie egzaminowe — testuje zrozumienie warunków Greena!

Krok 1: Identyfikacja pola i sprawdzenie rotacji

Pole wektorowe: \(P = \dfrac{-y}{x^2+y^2},\quad Q = \dfrac{x}{x^2+y^2}\).

Obliczamy pochodne (iloraz):

\[\frac{\partial Q}{\partial x} = \frac{(x^2+y^2) - x \cdot 2x}{(x^2+y^2)^2} = \frac{y^2 - x^2}{(x^2+y^2)^2}\] \[\frac{\partial P}{\partial y} = \frac{-(x^2+y^2) - (-y) \cdot 2y}{(x^2+y^2)^2} = \frac{y^2 - x^2}{(x^2+y^2)^2}\]

Rotacja = 0 wszędzie, gdzie pole jest określone (tzn. poza \((0,0)\)).

Krok 2: Przypadek (b) — \((0,0) \notin S\)

Pole jest gładkie na całym \(S\) (brak osobliwości), rotacja = 0 ⇒ z tw. Greena:

\[\boxed{\oint_C \frac{x\,\mathrm{d}y - y\,\mathrm{d}x}{x^2+y^2} = \iint_S 0\,\mathrm{d}A = 0}\]

Krok 3: Przypadek (a) — \((0,0) \in S\) (sztuczka z małym okręgiem)

Problem: Pole ma osobliwość w \((0,0) \in S\), więc nie wolno stosować Greena bezpośrednio.

Sztuczka: Otaczamy \((0,0)\) małym okręgiem \(C_\varepsilon\) o promieniu \(\varepsilon\), orientacja ujemna (CW — bo jest brzegiem wewnętrznym).

Na pierścieniu \(D_\varepsilon = S \setminus B(0,\varepsilon)\) pole jest gładkie i rotacja = 0, więc z Greena:

\[\oint_C - \oint_{C_\varepsilon^+} = \iint_{D_\varepsilon} 0\,\mathrm{d}A = 0\]

Zatem \(\oint_C = \oint_{C_\varepsilon^+}\) (oba z orientacją CCW).

Liczymy wprost na \(C_\varepsilon\): \(x = \varepsilon\cos t,\; y = \varepsilon\sin t,\; t \in [0, 2\pi]\).

\[x\,\mathrm{d}y - y\,\mathrm{d}x = \varepsilon\cos t \cdot \varepsilon\cos t\,\mathrm{d}t - \varepsilon\sin t \cdot (-\varepsilon\sin t)\,\mathrm{d}t\] \[= \varepsilon^2(\cos^2 t + \sin^2 t)\,\mathrm{d}t = \varepsilon^2\,\mathrm{d}t\] \[x^2 + y^2 = \varepsilon^2\] \[\oint_{C_\varepsilon} = \int_0^{2\pi} \frac{\varepsilon^2}{\varepsilon^2}\,\mathrm{d}t = \int_0^{2\pi} \mathrm{d}t = 2\pi\] \[\boxed{\oint_C \frac{x\,\mathrm{d}y - y\,\mathrm{d}x}{x^2+y^2} = 2\pi}\]

Morał: Wynik nie zależy od kształtu \(C\) ani od \(\varepsilon\) — liczy się tylko, czy osobliwość jest wewnątrz czy na zewnątrz.

Twoja kolej 3: Green na trójkącie  (Egzamin 2025, Zad. 4)

Zadanie

Oblicz \(\displaystyle\oint_\Gamma 2(x^2+y^2)\,\mathrm{d}x + (x+y)^2\,\mathrm{d}y\), gdzie \(\Gamma\) = brzeg trójkąta \(A(1,1),\; B(2,2),\; C(1,3)\), orientacja dodatnia.

Krok 1: Green — rotacja

Krzywa zamknięta, orientacja dodatnia ⇒ Green.

\[P = 2(x^2 + y^2), \quad Q = (x+y)^2\] \[\frac{\partial Q}{\partial x} = 2(x+y), \qquad \frac{\partial P}{\partial y} = 4y\]

Rotacja:

\[\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} = 2(x+y) - 4y = 2x + 2y - 4y = 2x - 2y\]

Krok 2: Granice całkowania po trójkącie

Wierzchołki: \(A(1,1),\; B(2,2),\; C(1,3)\).

Krawędzie:

  • \(AB\): \(y = x\) (od \(x=1\) do \(x=2\))
  • \(BC\): z \((2,2)\) do \((1,3)\): \(y = -x + 4\)
  • \(CA\): \(x = 1\) (od \(y=3\) do \(y=1\))

Rzut na oś \(x\): \(x \in [1, 2]\). Dla ustalonego \(x\):

  • Dolna granica: \(y = x\) (krawędź \(AB\))
  • Górna granica: \(y = -x + 4\) (krawędź \(BC\))
\[I = \int_1^2 \int_x^{-x+4} (2x - 2y)\,\mathrm{d}y\,\mathrm{d}x\]

Krok 3: Całka wewnętrzna

\[\int_x^{-x+4} (2x - 2y)\,\mathrm{d}y = \bigl[2xy - y^2\bigr]_{y=x}^{y=-x+4}\]

Górna granica \(y = -x+4\):

\[2x(-x+4) - (-x+4)^2 = -2x^2 + 8x - (x^2 - 8x + 16) = -3x^2 + 16x - 16\]

Dolna granica \(y = x\):

\[2x \cdot x - x^2 = x^2\]

Różnica:

\[-3x^2 + 16x - 16 - x^2 = -4x^2 + 16x - 16\]

Krok 4: Całka zewnętrzna

\[I = \int_1^2 (-4x^2 + 16x - 16)\,\mathrm{d}x = \left[-\frac{4x^3}{3} + 8x^2 - 16x\right]_1^2\]

Dla \(x = 2\):

\[-\frac{32}{3} + 32 - 32 = -\frac{32}{3}\]

Dla \(x = 1\):

\[-\frac{4}{3} + 8 - 16 = -\frac{4}{3} - 8 = -\frac{28}{3}\]

Wynik:

\[I = -\frac{32}{3} - \left(-\frac{28}{3}\right) = -\frac{32}{3} + \frac{28}{3} = -\frac{4}{3}\] \[\boxed{I = -\frac{4}{3}}\]

Twoja kolej 4: Green + współrzędne biegunowe  (Egzamin 2026, Zad. 4)

Zadanie

Oblicz \(\displaystyle\oint_\Gamma y^3\,\mathrm{d}x + x^3\,\mathrm{d}y\), gdzie \(\Gamma\) = okrąg jednostkowy \(x^2 + y^2 = 1\), orientacja dodatnia.

Krok 1: Green — rotacja

\(P = y^3,\; Q = x^3\).

\[\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} = 3x^2 - 3y^2 = 3(x^2 - y^2)\] \[I = \iint_D 3(x^2 - y^2)\,\mathrm{d}A\]

gdzie \(D\) = koło jednostkowe.

Krok 2: Przejście na biegunowe

\(x = r\cos\varphi,\; y = r\sin\varphi,\; \mathrm{d}A = r\,\mathrm{d}r\,\mathrm{d}\varphi\).

\[x^2 - y^2 = r^2\cos^2\varphi - r^2\sin^2\varphi = r^2\cos 2\varphi\] \[I = 3\int_0^{2\pi}\int_0^1 r^2\cos 2\varphi \cdot r\,\mathrm{d}r\,\mathrm{d}\varphi = 3\int_0^{2\pi}\cos 2\varphi\,\mathrm{d}\varphi \cdot \int_0^1 r^3\,\mathrm{d}r\]

Krok 3: Obliczenie

\[\int_0^{2\pi}\cos 2\varphi\,\mathrm{d}\varphi = \left[\frac{\sin 2\varphi}{2}\right]_0^{2\pi} = 0\]

Całka kątowa = 0 ⇒ cała całka = 0.

\[\boxed{I = 0}\]

Szybki argument: \(\cos 2\varphi\) ma pełny okres na \([0, 2\pi]\), więc całka = 0 bez rachunków.
