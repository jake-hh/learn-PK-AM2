RR II rzędu — zadania zbiorcze

Egzamin Zad. 6 Praktyka  ⏱ ~55 min

Czysta praktyka. Zadania z warunkami początkowymi (jak na egzaminie) + metoda uzmienniania stałych dla „trudnych” prawych stron, które MWN nie obsługuje.

Metoda uzmienniania stałych (variation of parameters)

Kiedy uzmiennianie zamiast MWN?

MWN działa tylko gdy \(h(x)\) to wielomian × eksponenta × trygonometria. Gdy \(h(x)\) jest czymś innym (np. \(\frac{1}{\cos x}\), \(\frac{e^x}{x}\), \(\frac{1}{1+e^x}\)), używamy uzmienniania.

Wzór — Uzmiennianie stałych  [WYKŁAD RR II rzędu]

Mając układ fundamentalny \((y_1, y_2)\) jednorodnego, szukamy \(y_s = C_1(x)\,y_1 + C_2(x)\,y_2\), gdzie:

\[\begin{cases} C_1'(x)\,y_1 + C_2'(x)\,y_2 = 0 \\[.3em] C_1'(x)\,y_1' + C_2'(x)\,y_2' = h(x) \end{cases}\]

Rozwiązujemy układ na \(C_1'(x)\) i \(C_2'(x)\), potem całkujemy.

Wroński: \(W = y_1 y_2' - y_2 y_1'\). Wtedy \(C_1' = -\frac{y_2 h}{W}\), \(C_2' = \frac{y_1 h}{W}\).

Pipeline: dwa rozw. bazowe + h(x) → układ na C₁', C₂' → całkowanie → y_s.

Zadanie 1: \(y'' + y = -\sin 2x\), \(\;y(\pi) = 1,\; y'(\pi) = 1\)  (Zad. 2.3b)

Przykład rozwiązany

Jednorodne: \(\lambda^2 + 1 = 0 \implies \lambda = \pm i\).

\[y_J = C_1\cos x + C_2\sin x\]

MWN: \(h(x) = -\sin 2x\). \(i\beta = 2i\) nie jest pierw. char. (\(\pm i\)) ⇒ \(s = 0\).

Postać: \(y_s = A\sin 2x + B\cos 2x\).

Pochodne i podstawienie:

\[y_s'' + y_s = -4A\sin 2x - 4B\cos 2x + A\sin 2x + B\cos 2x = -3A\sin 2x - 3B\cos 2x\] \[-3A = -1 \implies A = \tfrac{1}{3}, \qquad -3B = 0 \implies B = 0\]

Rozwiązanie ogólne:

\[y = C_1\cos x + C_2\sin x + \frac{\sin 2x}{3}\]

Warunki początkowe \(y(\pi) = 1\), \(y'(\pi) = 1\):

\[y(\pi) = C_1\cos\pi + C_2\sin\pi + \frac{\sin 2\pi}{3} = -C_1 = 1 \implies C_1 = -1\] \[y'(x) = -C_1\sin x + C_2\cos x + \frac{2\cos 2x}{3}\] \[y'(\pi) = 0 + C_2(-1) + \frac{2}{3} = 1 \implies C_2 = -\frac{1}{3}\] \[\boxed{y = -\cos x - \frac{\sin x}{3} + \frac{\sin 2x}{3}}\]

Twoja kolej: \(y'' - 2y' + 2y = 1\), \(\;y(0) = 0,\; y'(0) = 0\)  (Zad. 2.3c)

Rozwiąż samodzielnie

Pierw. char.: \(\lambda = 1 \pm i\). \(h(x) = 1\) — wielomian st. 0, \(\lambda = 0\) nie jest pierw. ⇒ \(y_s = A\).

Krok 1: Rozwiązanie ogólne

\[y_J = e^x(C_1\cos x + C_2\sin x)\]

Podstawiamy \(y_s = A\): \(0 - 0 + 2A = 1 \implies A = 1/2\).

\[y = e^x(C_1\cos x + C_2\sin x) + \frac{1}{2}\]

Krok 2: Warunki początkowe

\[y(0) = C_1 + \frac{1}{2} = 0 \implies C_1 = -\frac{1}{2}\] \[y'(x) = e^x\bigl[(C_1+C_2)\cos x + (C_2-C_1)\sin x\bigr]\] \[y'(0) = C_1 + C_2 = 0 \implies C_2 = \frac{1}{2}\] \[\boxed{y = \frac{1}{2}\bigl[1 - e^x(\cos x - \sin x)\bigr]}\]

Twoja kolej: \(y'' - 2y' + y = e^x\), \(\;y(0) = 0,\; y'(0) = 1\)  (Zad. 2.3e)

Podwójny rezonans!

\(\lambda = 1\) podwójny. \(\alpha = 1\) = podwójny pierw. ⇒ \(s = 2\), \(y_s = Ax^2 e^x\).

Krok 1: Rozwiązanie ogólne

\[y_J = (C_1 + C_2 x)e^x\]

Podstawiamy \(y_s = Ax^2 e^x\):

\[y_s' = Ae^x(x^2 + 2x), \qquad y_s'' = Ae^x(x^2 + 4x + 2)\] \[y_s'' - 2y_s' + y_s = Ae^x\bigl[(x^2+4x+2) - 2(x^2+2x) + x^2\bigr] = 2Ae^x\] \[2A = 1 \implies A = \frac{1}{2}\] \[y = (C_1 + C_2 x)e^x + \frac{x^2}{2}e^x\]

Krok 2: Warunki początkowe

\[y(0) = C_1 = 0\] \[y'(x) = C_2 e^x + C_2 xe^x + xe^x + \frac{x^2}{2}e^x = e^x\!\left(C_2 + C_2 x + x + \frac{x^2}{2}\right)\] \[y'(0) = C_2 = 1\] \[\boxed{y = xe^x + \frac{x^2}{2}e^x = e^x\!\left(x + \frac{x^2}{2}\right)}\]

Przykład rozwiązany: \(y'' + 4y' + 4y = \frac{e^{-2x}}{x^2}\)  (Zad. 2.4a)

Metoda uzmienniania stałych

Jednorodne: \(\lambda^2 + 4\lambda + 4 = (\lambda+2)^2 = 0 \implies \lambda = -2\) (podwójny).

\[y_1 = e^{-2x}, \quad y_2 = xe^{-2x}\]

Układ na \(C_1', C_2'\):

\[\begin{cases} C_1'\,e^{-2x} + C_2'\,xe^{-2x} = 0 \\[.3em] C_1'(-2e^{-2x}) + C_2'(e^{-2x} - 2xe^{-2x}) = \frac{e^{-2x}}{x^2} \end{cases}\]

Z pierwszego: \(C_1' = -xC_2'\). Wstawiamy do drugiego:

\[-xC_2'(-2e^{-2x}) + C_2'(e^{-2x} - 2xe^{-2x}) = \frac{e^{-2x}}{x^2}\] \[C_2' e^{-2x}(2x + 1 - 2x) = \frac{e^{-2x}}{x^2}\] \[C_2' = \frac{1}{x^2}\]

Całkowanie:

\[C_2 = \int\frac{1}{x^2}\,dx = -\frac{1}{x}\] \[C_1' = -x \cdot \frac{1}{x^2} = -\frac{1}{x} \implies C_1 = -\ln|x|\]

Rozwiązanie szczególne:

\[y_s = -\ln|x| \cdot e^{-2x} + \left(-\frac{1}{x}\right)xe^{-2x} = -e^{-2x}(\ln|x| + 1)\]

Rozwiązanie ogólne:

\[\boxed{y = (C_1 + C_2 x)e^{-2x} - e^{-2x}(\ln|x| + 1)}\]

Twoja kolej: \(y'' + 4y = \frac{1}{\cos 2x}\)  (Zad. 2.4b)

Uzmiennianie stałych

Jednorodne: \(\lambda = \pm 2i\), \(y_1 = \cos 2x\), \(y_2 = \sin 2x\). Wroński: \(W = 2\).

Krok 1: \(C_1'\) i \(C_2'\)

\[C_1' = -\frac{y_2 \cdot h}{W} = -\frac{\sin 2x}{2\cos 2x} = -\frac{\tan 2x}{2}\] \[C_2' = \frac{y_1 \cdot h}{W} = \frac{\cos 2x}{2\cos 2x} = \frac{1}{2}\]

Krok 2: Całkowanie i wynik

\[C_1 = -\frac{1}{2}\int\tan 2x\,dx = \frac{1}{4}\ln|\cos 2x|\] \[C_2 = \frac{x}{2}\] \[y_s = \frac{\cos 2x}{4}\ln|\cos 2x| + \frac{x\sin 2x}{2}\] \[\boxed{y = C_1\cos 2x + C_2\sin 2x + \frac{\cos 2x}{4}\ln|\cos 2x| + \frac{x\sin 2x}{2}}\]

Twoja kolej: \(y'' + 2y' + 5y = 3\), \(\;y(0) = 1,\; y'(0) = 0\)  (Zad. 2.3d)

MWN + warunek początkowy

Pierw. char.: \(\lambda = -1 \pm 2i\). \(h(x) = 3\), \(\lambda = 0\) nie jest pierw. ⇒ \(y_s = A\).

Krok 1: Rozwiązanie ogólne

\[y_J = e^{-x}(C_1\cos 2x + C_2\sin 2x)\]

\(y_s = A\): \(5A = 3 \implies A = 3/5\).

\[y = e^{-x}(C_1\cos 2x + C_2\sin 2x) + \frac{3}{5}\]

Krok 2: Warunki początkowe

\[y(0) = C_1 + \frac{3}{5} = 1 \implies C_1 = \frac{2}{5}\] \[y'(x) = e^{-x}\bigl[(-C_1+2C_2)\cos 2x + (-C_2-2C_1)\sin 2x\bigr]\] \[y'(0) = -C_1 + 2C_2 = 0 \implies C_2 = \frac{C_1}{2} = \frac{1}{5}\] \[\boxed{y = \frac{e^{-x}}{5}(2\cos 2x + \sin 2x) + \frac{3}{5}}\]
