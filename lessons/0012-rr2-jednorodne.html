RR II rzędu jednorodne — równanie charakterystyczne

Egzamin Zad. 6 Teoria+Praktyka  ⏱ ~35 min

Zad. 6 na egzaminie to zawsze RR II rzędu. Zaczynamy od jednorodnych ze stałymi współczynnikami — tutaj cała robota sprowadza się do rozwiązania równania kwadratowego.

Segment 1: Struktura rozwiązania RR II rzędu

Definicja — Liniowe RR II rzędu ze stałymi współczynnikami  [WYKŁAD RR II rzędu]

Równanie postaci:

\[y'' + py' + qy = h(x)\]

gdzie \(p, q \in \mathbb{R}\) to stałe, a \(h(x)\) to znana funkcja.

  • Jednorodne (LJ): \(h(x) \equiv 0\), czyli \(y'' + py' + qy = 0\)
  • Niejednorodne (LN): \(h(x) \not\equiv 0\)
Twierdzenie — Struktura rozwiązania ogólnego  [WYKŁAD RR II rzędu]

Rozwiązanie ogólne (LN) ma postać:

\[\boxed{y = y_J + y_s}\]

gdzie:

  • \(y_J = C_1 y_1 + C_2 y_2\) — rozwiązanie ogólne jednorodnego (z dwoma stałymi)
  • \(y_s\) — dowolne rozwiązanie szczególne niejednorodnego

Dlatego zawsze zaczynamy od rozwiązania jednorodnego!

Porównanie z RR I rzędu

W L09–L11 robiliśmy to samo, tylko z jedną stałą \(C\). Tutaj mamy dwie stałe \(C_1, C_2\), bo równanie jest II rzędu. Reszta logiki jest analogiczna.

Segment 2: Równanie charakterystyczne — 3 przypadki

Dla jednorodnego \(y'' + py' + qy = 0\) zgadujemy rozwiązanie \(y = e^{\lambda x}\). Po podstawieniu dostajemy:

\[e^{\lambda x}(\lambda^2 + p\lambda + q) = 0\]

Ponieważ \(e^{\lambda x} \neq 0\), musi zachodzić:

Równanie charakterystyczne
\[\boxed{\lambda^2 + p\lambda + q = 0}\]

To zwykłe równanie kwadratowe! Wyróżnik: \(\Delta = p^2 - 4q\).

W zależności od \(\Delta\) mamy 3 przypadki:

Przypadek 1 — \(\Delta > 0\): dwa różne pierwiastki rzeczywiste \(\lambda_1 \neq \lambda_2\)
\[\boxed{y_J = C_1 e^{\lambda_1 x} + C_2 e^{\lambda_2 x}}\]
Przypadek 2 — \(\Delta = 0\): podwójny pierwiastek \(\lambda\)
\[\boxed{y_J = C_1 e^{\lambda x} + C_2\, x e^{\lambda x} = (C_1 + C_2 x)\,e^{\lambda x}}\]

Drugie rozwiązanie to \(xe^{\lambda x}\), nie samo \(e^{\lambda x}\) — bo potrzebujemy dwóch liniowo niezależnych rozwiązań.

Przypadek 3 — \(\Delta < 0\): pierwiastki zespolone \(\lambda = \alpha \pm i\beta\)
\[\boxed{y_J = e^{\alpha x}\bigl(C_1 \cos\beta x + C_2 \sin\beta x\bigr)}\]

gdzie \(\alpha = -p/2\), \(\beta = \sqrt{|{\Delta}|}/2\).

Fizyczna interpretacja: tłumione drgania. \(e^{\alpha x}\) to obwiednia, \(\cos/\sin\) to oscylacje.

Mnemonik
  • \(\Delta > 0\) → dwa \(e\) → dwa eksponenty
  • \(\Delta = 0\) → jeden \(e\), ale mnożymy przez \(x\) → \((C_1 + C_2 x)e^{\lambda x}\)
  • \(\Delta < 0\) → zespolone → \(e^{\alpha x}(\cos + \sin)\)

Algorytm: RR II rzędu jednorodne ze stałymi współczynnikami

  1. Zapisz równanie w postaci \(y'' + py' + qy = 0\)
  2. Wypisz równanie charakterystyczne: \(\lambda^2 + p\lambda + q = 0\)
  3. Oblicz \(\Delta = p^2 - 4q\) i znajdź pierwiastki
  4. Zapisz \(y_J\) wg odpowiedniego przypadku (1, 2 lub 3)

Przykład rozwiązany: \(y'' - 4y' + 4y = 0\)  (Lista 5, Zad. 2.1a)

Rozwiązanie

Równanie char.: \(\lambda^2 - 4\lambda + 4 = 0\)

\[\Delta = 16 - 16 = 0 \implies \lambda = 2 \text{ (podwójny)}\]

Przypadek 2 (\(\Delta = 0\)):

\[\boxed{y = (C_1 + C_2 x)\,e^{2x}}\]

Rozgrzewka: \(y'' - y = 0\)  (Zad. 2.1c)

Rozwiąż

Równanie char., delta, pierwiastki, rozwiązanie ogólne.

\(\lambda^2 - 1 = 0 \implies \lambda_1 = 1,\; \lambda_2 = -1\). Przypadek 1:

\[\boxed{y = C_1 e^x + C_2 e^{-x}}\]

Twoja kolej: \(y'' + y' + y = 0\)  (Zad. 2.1b)

Przypadek 3!

Oblicz \(\Delta\). Będzie ujemny — wypisz \(\alpha\) i \(\beta\), zapisz rozwiązanie.

Krok 1: Równanie char. i \(\Delta\)

\[\lambda^2 + \lambda + 1 = 0, \qquad \Delta = 1 - 4 = -3 < 0\]

Krok 2: Pierwiastki i rozwiązanie

\[\lambda = \frac{-1 \pm i\sqrt{3}}{2}, \qquad \alpha = -\frac{1}{2},\; \beta = \frac{\sqrt{3}}{2}\] \[\boxed{y = e^{-x/2}\!\left(C_1 \cos\frac{\sqrt{3}}{2}x + C_2 \sin\frac{\sqrt{3}}{2}x\right)}\]

Twoja kolej: \(y'' + 2y' + 2y = 0\)  (Zad. 2.1d)

Znowu przypadek 3

Pełny algorytm. Jaki jest \(\alpha\)? Jaki \(\beta\)?

Krok 1: \(\Delta\) i pierwiastki

\[\lambda^2 + 2\lambda + 2 = 0, \qquad \Delta = 4 - 8 = -4\] \[\lambda = \frac{-2 \pm 2i}{2} = -1 \pm i, \qquad \alpha = -1,\; \beta = 1\]

Krok 2: Rozwiązanie ogólne

\[\boxed{y = e^{-x}(C_1 \cos x + C_2 \sin x)}\]

Twoja kolej: \(y'' - 5y' + 4y = 0\)  (Zad. 2.1e)

Przypadek 1

Delta dodatnia. Znajdź dwa różne pierwiastki.

\[\lambda^2 - 5\lambda + 4 = 0 \implies (\lambda - 1)(\lambda - 4) = 0 \implies \lambda_1 = 1,\; \lambda_2 = 4\] \[\boxed{y = C_1 e^x + C_2 e^{4x}}\]

Twoja kolej: \(y'' - 4y' + 13y = 0\)  (Zad. 2.1f)

Przypadek 3 — trudniejszy

Uwaga na \(\beta\) — nie zgub dwójki w mianowniku.

Rozwiązanie

\[\lambda^2 - 4\lambda + 13 = 0, \qquad \Delta = 16 - 52 = -36\] \[\lambda = \frac{4 \pm 6i}{2} = 2 \pm 3i, \qquad \alpha = 2,\; \beta = 3\] \[\boxed{y = e^{2x}(C_1 \cos 3x + C_2 \sin 3x)}\]

Gdy \(\Delta = 0\) (podwójny pierwiastek \(\lambda\)), drugie rozwiązanie bazowe to:
\(e^{2\lambda x}\)
\(\lambda x \cdot e^{\lambda x}\)
\(x \cdot e^{\lambda x}\)
\(x^2 \cdot e^{\lambda x}\)
Przy podwójnym pierwiastku mnożymy przez \(x\): \(y_1 = e^{\lambda x}\), \(y_2 = xe^{\lambda x}\).
Rozwiązanie \(y'' - y = 0\) to:
\(C_1 e^x + C_2 e^{-x}\)
\((C_1 + C_2 x)e^x\)
\(C_1 \cos x + C_2 \sin x\)
\(C_1 e^x + C_2 x e^x\)

\(e^{3x}(C_1\cos 2x + C_2\sin 2x)\)

Wynik: — / 2
Podaj równanie charakterystyczne dla \(y'' + py' + qy = 0\) i opisz 3 przypadki rozwiązań.

\(\lambda^2 + p\lambda + q = 0\), \(\;\Delta = p^2 - 4q\):

  • \(\Delta > 0\): \(\lambda_1 \neq \lambda_2\) ⇒ \(y = C_1 e^{\lambda_1 x} + C_2 e^{\lambda_2 x}\)
  • \(\Delta = 0\): \(\lambda\) podwójny ⇒ \(y = (C_1 + C_2 x)e^{\lambda x}\)
  • \(\Delta < 0\): \(\lambda = \alpha \pm i\beta\) ⇒ \(y = e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)\)
Jak wygląda rozwiązanie ogólne niejednorodnego \(y'' + py' + qy = h(x)\)?
\[y = \underbrace{C_1 y_1 + C_2 y_2}_{y_J} + \underbrace{y_s}_{\text{szczeg.}}\]

\(y_J\) — rozwiązanie ogólne jednorodnego. \(y_s\) — jedno konkretne rozwiązanie niejednorodnego.

Masz pytania? Mogę wyjaśnić skąd bierze się \(xe^{\lambda x}\) w przypadku 2, dlaczego zespolone dają cos/sin, albo pomóc z dowolnym zadaniem z Listy 5. Dalej: L13 — metoda przewidywanych współczynników dla niejednorodnych.
