Pelne rozwiazania wszystkich 12 zadan z obu egzaminow praktycznych. Kazdy krok w osobnym bloku — sprobuj najpierw sam, potem odkryj.

Jak korzystac

Egzamin — 24 czerwca 2025, Termin 1

Zadanie 1 — Badanie funkcji \(f(x) = x\,e^{1/x}\)

Tresc
Wyznacz asymptoty, ekstrema lokalne i przedzialy monotonicznosci funkcji \[f(x) = x\,e^{1/x}\]

Krok 1: Dziedzina

\(e^{1/x}\) wymaga \(x \neq 0\). \[\mathcal{D} = (-\infty, 0) \cup (0, +\infty)\]

Krok 2: Asymptoty

Asymptota pionowa \(x = 0\):

\[\lim_{x\to 0^+} x\,e^{1/x} \stackrel{t=1/x}{=} \lim_{t\to+\infty}\frac{e^t}{t} = +\infty\] \[\lim_{x\to 0^-} x\,e^{1/x} \stackrel{t=1/x}{=} \lim_{t\to-\infty}\frac{e^t}{t} = \frac{0}{-\infty} = 0\] Jednostronna asymptota pionowa \(x = 0\) (od strony prawej).

Asymptota ukosna \(y = ax + b\):

\[a = \lim_{x\to\pm\infty}\frac{f(x)}{x} = \lim_{x\to\pm\infty} e^{1/x} = e^0 = 1\] \[b = \lim_{x\to\pm\infty}\bigl(f(x) - x\bigr) = \lim_{x\to\pm\infty} x\bigl(e^{1/x} - 1\bigr) \stackrel{t=1/x}{=} \lim_{t\to 0}\frac{e^t - 1}{t} = 1\] Asymptota ukosna: \(y = x + 1\) (obustronna).

Krok 3: Pochodna i monotonicznosc

\[f'(x) = e^{1/x} + x\cdot e^{1/x}\cdot\!\left(-\tfrac{1}{x^2}\right) = e^{1/x}\!\left(1 - \tfrac{1}{x}\right) = e^{1/x}\cdot\frac{x-1}{x}\]

\(e^{1/x} > 0\) zawsze, wiec znak zalezy od \(\frac{x-1}{x}\):

\(x\)\((-\infty,0)\)\(0\)\((0,1)\)\(1\)\((1,+\infty)\)
\(x-1\)−−0+
\(x\)−+++
\(f'(x)\)+−0+
\(f\)↗↘min↗

\(f\) rosnie na \((-\infty, 0)\) i \((1, +\infty)\), maleje na \((0, 1)\).

Krok 4: Ekstrema

Minimum lokalne w \(x = 1\): \[f(1) = 1 \cdot e^1 = e\] Brak maximum (w \(x=0\) funkcja nie jest okreslona — zmiana z rosniacej na malejaca nie daje ekstremum, bo jest przerwa w dziedzinie).

Zadanie 2 — Ekstrema \(f(x,y) = x^3 + y^3 - 9xy\)

Tresc
Znalezc ekstrema lokalne funkcji \(f(x,y) = x^3 + y^3 - 9xy\).

Krok 1: Punkty stacjonarne

\[f_x = 3x^2 - 9y = 0 \;\Longrightarrow\; y = \tfrac{x^2}{3}\] \[f_y = 3y^2 - 9x = 0 \;\Longrightarrow\; y^2 = 3x\] Podstawiamy \(y = x^2/3\) do drugiego: \[\left(\frac{x^2}{3}\right)^2 = 3x \;\Longrightarrow\; \frac{x^4}{9} = 3x \;\Longrightarrow\; x^4 = 27x \;\Longrightarrow\; x(x^3 - 27) = 0\]
  • \(x = 0 \Rightarrow y = 0\): punkt \((0, 0)\)
  • \(x = 3 \Rightarrow y = 3\): punkt \((3, 3)\)

Krok 2: Macierz Hessego

\[f_{xx} = 6x,\quad f_{yy} = 6y,\quad f_{xy} = -9\] \[H = f_{xx}\,f_{yy} - f_{xy}^2 = 36xy - 81\]

Punkt \((0,0)\): \(H = 0 - 81 = -81 < 0\) → punkt siodlowy.

Punkt \((3,3)\): \(H = 36 \cdot 9 - 81 = 324 - 81 = 243 > 0\), \(f_{xx} = 18 > 0\) → minimum lokalne.

Minimum lokalne w \((3, 3)\): \[f(3,3) = 27 + 27 - 81 = -27\]

Zadanie 3 — Calka podwojna \(\iint_D (x+y)\,dx\,dy\)

Tresc
Obliczyc calke \(\displaystyle\iint_D (x+y)\,dx\,dy\), gdzie \(D\) jest obszarem ograniczonym krzywa \(x^2 + y^2 - x - y = 0\).

Krok 1: Identyfikacja obszaru

Uzupelniamy do kwadratow: \[x^2 - x + y^2 - y = 0 \;\Longrightarrow\; \left(x - \tfrac{1}{2}\right)^2 + \left(y - \tfrac{1}{2}\right)^2 = \tfrac{1}{2}\] Kolo o srodku \(\bigl(\tfrac{1}{2},\tfrac{1}{2}\bigr)\) i promieniu \(r = \tfrac{1}{\sqrt{2}}\).

Krok 2: Wspolrzedne biegunowe

Rownanie w biegunowych (\(x = r\cos\theta,\; y = r\sin\theta\)): \[r^2 - r\cos\theta - r\sin\theta = 0 \;\Longrightarrow\; r = \cos\theta + \sin\theta\] Warunek \(r \ge 0\): \(\cos\theta + \sin\theta \ge 0\), czyli \(\theta \in [-\tfrac{\pi}{4},\, \tfrac{3\pi}{4}]\).

Krok 3: Ustawienie calki

\[\iint_D (x+y)\,dx\,dy = \int_{-\pi/4}^{3\pi/4}\!\int_0^{\cos\theta+\sin\theta} r(\cos\theta+\sin\theta)\cdot r\,dr\,d\theta\] Podcalkowa: \(r^2(\cos\theta+\sin\theta)\). Calkujemy po \(r\): \[= \int_{-\pi/4}^{3\pi/4} (\cos\theta+\sin\theta)\cdot \frac{(\cos\theta+\sin\theta)^3}{3}\,d\theta = \frac{1}{3}\int_{-\pi/4}^{3\pi/4}(\cos\theta+\sin\theta)^4\,d\theta\]

Krok 4: Obliczenie calki

Podstawienie: \(\cos\theta + \sin\theta = \sqrt{2}\sin(\theta + \tfrac{\pi}{4})\), oraz \(u = \theta + \tfrac{\pi}{4}\): \[= \frac{1}{3}\int_0^{\pi} \bigl(\sqrt{2}\sin u\bigr)^4\,du = \frac{4}{3}\int_0^{\pi}\sin^4 u\,du\] Korzystamy ze wzoru redukcyjnego: \[\int_0^{\pi}\sin^4 u\,du = \frac{3\pi}{8}\] \[= \frac{4}{3}\cdot\frac{3\pi}{8} = \frac{4\pi}{8}\]
Wynik: \(\displaystyle\iint_D (x+y)\,dx\,dy = \frac{\pi}{2}\)

Zadanie 4 — Calka krzywoliniowa (trojkat)

Tresc
Oblicz calke \[\oint_\Gamma 2(x^2+y^2)\,dx + (x+y)^2 y\,dy\] gdzie \(\Gamma\) jest brzegiem trojkata o wierzcholkach \(A(1,1)\), \(B(2,2)\), \(C(1,3)\), skierowanym dodatnio.

Krok 1: Twierdzenie Greena

\(P = 2(x^2+y^2)\), \(Q = (x+y)^2 y\). \[\frac{\partial Q}{\partial x} = 2(x+y)\cdot y,\qquad \frac{\partial P}{\partial y} = 4y\] \[\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} = 2y(x+y) - 4y = 2xy + 2y^2 - 4y = 2y(x + y - 2)\]

Krok 2: Granice calkowania

Boki trojkata:
  • \(AB\): \(y = x\), od \(x=1\) do \(x=2\) (dolna granica)
  • \(BC\): \(y = -x + 4\), od \(x=2\) do \(x=1\) (gorna granica)
  • \(CA\): \(x = 1\), od \(y=3\) do \(y=1\) (lewy bok)
Dla \(x \in [1, 2]\): \(y\) od \(x\) (dol) do \(-x+4\) (gora). \[\iint_D 2y(x+y-2)\,dA = \int_1^2\!\int_x^{4-x} (2xy + 2y^2 - 4y)\,dy\,dx\]

Krok 3: Calka wewnetrzna

\[\int_x^{4-x}(2xy + 2y^2 - 4y)\,dy = \Bigl[xy^2 + \tfrac{2}{3}y^3 - 2y^2\Bigr]_x^{4-x}\]

Przy \(y = 4-x\):

\[x(4-x)^2 + \tfrac{2}{3}(4-x)^3 - 2(4-x)^2\]

Przy \(y = x\):

\[x^3 + \tfrac{2}{3}x^3 - 2x^2 = \tfrac{5}{3}x^3 - 2x^2\]

Po rozwinieciu (4-x)^3 = 64-48x+12x^2-x^3 i uproszczeniu roznica wynosi:

\[-\tfrac{4}{3}x^3 + \tfrac{32}{3}\]

Krok 4: Calka zewnetrzna

\[\int_1^2\!\left(-\frac{4}{3}x^3 + \frac{32}{3}\right)dx = \left[-\frac{x^4}{3} + \frac{32x}{3}\right]_1^2 = \left(-\frac{16}{3} + \frac{64}{3}\right) - \left(-\frac{1}{3} + \frac{32}{3}\right)\] \[= \frac{48}{3} - \frac{31}{3}\]
Wynik: \(\displaystyle\oint_\Gamma = \frac{17}{3}\)

Zadanie 5 — RR I rzedu: \(y' - y\sin x = -\sin x\)

Tresc
Rozwiazac zagadnienie poczatkowe: \[y' - y\sin x = -\sin x,\qquad y\!\left(\tfrac{\pi}{2}\right) = 2\]

Krok 1: Czynnik calkujacy

Rownanie liniowe \(y' + P(x)\,y = Q(x)\) z \(P(x) = -\sin x\), \(Q(x) = -\sin x\). \[\mu(x) = e^{\int -\sin x\,dx} = e^{\cos x}\]

Krok 2: Rozwiazanie ogolne

Mnozymy przez \(\mu\): \[\bigl(y\,e^{\cos x}\bigr)' = -\sin x \cdot e^{\cos x}\] Calkujemy (podstawienie \(u = \cos x\), \(du = -\sin x\,dx\)): \[y\,e^{\cos x} = \int -\sin x\cdot e^{\cos x}\,dx = e^{\cos x} + C\] \[y = 1 + C\,e^{-\cos x}\]

Krok 3: Warunek poczatkowy

\[y\!\left(\tfrac{\pi}{2}\right) = 1 + C\,e^{-\cos(\pi/2)} = 1 + C\,e^0 = 1 + C = 2 \;\Longrightarrow\; C = 1\]
Wynik: \(\displaystyle y = 1 + e^{-\cos x}\)

Zadanie 6 — RR II rzedu: \(y'' + 6y' + 9y = 13\cos 2x\)

Tresc
Rozwiazac rownanie rozniczkowe: \[y'' + 6y' + 9y = 13\cos 2x\]

Krok 1: Rownanie charakterystyczne

\[r^2 + 6r + 9 = 0 \;\Longrightarrow\; (r+3)^2 = 0 \;\Longrightarrow\; r = -3 \text{ (podwojny)}\] \[y_h = (C_1 + C_2 x)\,e^{-3x}\]

Krok 2: Rozwiazanie szczegolne

Probujemy \(y_p = A\cos 2x + B\sin 2x\): \[y_p'' = -4A\cos 2x - 4B\sin 2x\] Podstawiamy do rownania: \[(-4A + 12B + 9A)\cos 2x + (-4B - 12A + 9B)\sin 2x = 13\cos 2x\] \[(5A + 12B)\cos 2x + (5B - 12A)\sin 2x = 13\cos 2x\] Uklad: \[\begin{cases} 5A + 12B = 13 \\ -12A + 5B = 0 \end{cases} \;\Longrightarrow\; B = \frac{12A}{5}\] \[5A + 12\cdot\frac{12A}{5} = 13 \;\Longrightarrow\; \frac{25A + 144A}{5} = 13 \;\Longrightarrow\; 169A = 65 \;\Longrightarrow\; A = \frac{5}{13}\] \[B = \frac{12}{5}\cdot\frac{5}{13} = \frac{12}{13}\]

Krok 3: Rozwiazanie ogolne

Wynik: \[y = (C_1 + C_2 x)\,e^{-3x} + \frac{5}{13}\cos 2x + \frac{12}{13}\sin 2x\]

Zadanie 1 — Badanie funkcji \(f(x) = x^3 e^{-x}\)

Tresc
Zbadaj funkcje \(f(x) = x^3 e^{-x}\). Wyznacz: dziedzine, asymptoty, monotonicznosc i ekstrema lokalne.

Krok 1: Dziedzina

Oba skladniki okreslone dla kazdego \(x\). \[\mathcal{D} = \mathbb{R}\]

Krok 2: Asymptoty

Brak asymptot pionowych — funkcja ciagla na calym \(\mathbb{R}\).

Granica w \(+\infty\):

\[\lim_{x\to+\infty}\frac{x^3}{e^x} = 0 \qquad\text{(eksponenta bije wielomian)}\] Asymptota pozioma \(y = 0\) w \(+\infty\).

Granica w \(-\infty\):

\(x^3 \to -\infty\) i \(e^{-x} \to +\infty\), wiec \(f(x) \to -\infty\). Brak asymptoty w \(-\infty\).

Krok 3: Pochodna i monotonicznosc

\[f'(x) = 3x^2 e^{-x} - x^3 e^{-x} = x^2 e^{-x}(3 - x)\] \(x^2 \ge 0\), \(e^{-x} > 0\), wiec znak zalezy od \((3-x)\):
\(x\)\((-\infty,0)\)\(0\)\((0,3)\)\(3\)\((3,+\infty)\)
\(x^2\)+0+++
\(3-x\)+++0−
\(f'(x)\)+0+0−
\(f\)↗↗max↘

\(f\) rosnie na \((-\infty, 3)\), maleje na \((3, +\infty)\).

\(x = 0\): f' nie zmienia znaku → brak ekstremum.

Krok 4: Ekstrema

Maximum lokalne w \(x = 3\): \[f(3) = 27\,e^{-3} = \frac{27}{e^3}\]

Zadanie 2 — Ekstrema \(f(x,y) = x^4 + y^4 - 4x^2 y + 2y^2\)

Tresc
Znalezc ekstrema lokalne funkcji \(f(x,y) = x^4 + y^4 - 4x^2 y + 2y^2\).

Krok 1: Punkty stacjonarne

\[f_x = 4x^3 - 8xy = 4x(x^2 - 2y) = 0\] \[f_y = 4y^3 - 4x^2 + 4y = 4(y^3 - x^2 + y) = 0\]

Przypadek 1: \(x = 0\) → \(y^3 + y = 0\) → \(y(y^2 + 1) = 0\) → \(y = 0\). Punkt: \((0, 0)\).

Przypadek 2: \(x^2 = 2y\) → podstawiamy do \(f_y = 0\):

\[y^3 - 2y + y = 0 \;\Longrightarrow\; y^3 - y = 0 \;\Longrightarrow\; y(y^2 - 1) = 0\]
  • \(y = 0 \Rightarrow x^2 = 0\): punkt \((0,0)\) (juz mamy)
  • \(y = 1 \Rightarrow x^2 = 2\): punkty \((\sqrt{2}, 1)\) i \((-\sqrt{2}, 1)\)
  • \(y = -1 \Rightarrow x^2 = -2\): brak rozwiazania

Krok 2: Macierz Hessego

\[f_{xx} = 12x^2 - 8y,\quad f_{yy} = 12y^2 + 4,\quad f_{xy} = -8x\] \[H = f_{xx}\,f_{yy} - f_{xy}^2\]

Punkt \((0,0)\): \(f_{xx} = 0\), \(f_{yy} = 4\), \(f_{xy} = 0\). \(H = 0\) — kryterium nierozstrzygajace.

Sprawdzamy bezposrednio. Na prostej \(y = x^2/2\):

\[f(x,\, x^2/2) = x^4 + x^8/16 - 2x^4 + x^4/2 = x^8/16 - x^4/2\] Dla malych \(x\): \(\approx -x^4/2 < 0\), ale \(f(0,0) = 0\). Na prostej \(y = 0\): \(f(x,0) = x^4 > 0\). Wiec \(f\) przyjmuje wartosci > 0 i < 0 w otoczeniu \((0,0)\) → punkt siodlowy.

Punkt \((\sqrt{2}, 1)\): \(f_{xx} = 24 - 8 = 16\), \(f_{yy} = 12 + 4 = 16\), \(f_{xy} = -8\sqrt{2}\).

\[H = 16\cdot 16 - 128 = 256 - 128 = 128 > 0,\quad f_{xx} = 16 > 0\] → minimum lokalne. Przez symetrie, \((-\sqrt{2}, 1)\) daje to samo.

Krok 3: Wartosc minimum

Minima lokalne w \((\sqrt{2},\, 1)\) i \((-\sqrt{2},\, 1)\): \[f(\pm\sqrt{2},\, 1) = 4 + 1 - 8 + 2 = -1\]

Zadanie 3 — Calka podwojna \(\iint_D (x^2+y^2)\,dx\,dy\)

Tresc
Oblicz calke \(\displaystyle\iint_D (x^2+y^2)\,dx\,dy\), gdzie \(D\colon x^2 + y^2 + x \le 0\).

Krok 1: Identyfikacja obszaru

\[x^2 + x + y^2 \le 0 \;\Longrightarrow\; \left(x + \tfrac{1}{2}\right)^2 + y^2 \le \tfrac{1}{4}\] Kolo o srodku \((-\tfrac{1}{2}, 0)\) i promieniu \(\tfrac{1}{2}\).

Krok 2: Wspolrzedne biegunowe

W biegunowych: \(r^2 + r\cos\theta \le 0\), czyli \(r \le -\cos\theta\). Wymaga \(\cos\theta \le 0\), wiec \(\theta \in [\tfrac{\pi}{2},\, \tfrac{3\pi}{2}]\). \[\iint_D (x^2+y^2)\,dx\,dy = \int_{\pi/2}^{3\pi/2}\!\int_0^{-\cos\theta} r^2 \cdot r\,dr\,d\theta = \int_{\pi/2}^{3\pi/2}\!\int_0^{-\cos\theta} r^3\,dr\,d\theta\]

Krok 3: Obliczenie

\[= \int_{\pi/2}^{3\pi/2}\frac{(-\cos\theta)^4}{4}\,d\theta = \frac{1}{4}\int_{\pi/2}^{3\pi/2}\cos^4\theta\,d\theta\] Wzor redukcyjny: \(\cos^4\theta = \tfrac{3}{8} + \tfrac{1}{2}\cos 2\theta + \tfrac{1}{8}\cos 4\theta\). \[\int_{\pi/2}^{3\pi/2}\cos^4\theta\,d\theta = \left[\frac{3\theta}{8} + \frac{\sin 2\theta}{4} + \frac{\sin 4\theta}{32}\right]_{\pi/2}^{3\pi/2} = \frac{9\pi}{16} - \frac{3\pi}{16} = \frac{3\pi}{8}\]
Wynik: \(\displaystyle\iint_D (x^2+y^2)\,dx\,dy = \frac{1}{4}\cdot\frac{3\pi}{8} = \frac{3\pi}{32}\)

Zadanie 4 — Calka krzywoliniowa (okrag)

Tresc
Oblicz calke krzywoliniowa: \[\oint_\Gamma y^3\,dx + x^3\,dy\] gdzie \(\Gamma\) to okrag \(x^2 + y^2 = 1\) (skierowany dodatnio).

Krok 1: Twierdzenie Greena

\(P = y^3\), \(Q = x^3\). \[\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} = 3x^2 - 3y^2 = 3(x^2 - y^2)\] \[\oint_\Gamma = \iint_D 3(x^2 - y^2)\,dA\]

Krok 2: Biegunowe

\(D\): kolo jednostkowe. \(x^2 - y^2 = r^2\cos 2\theta\). \[= 3\int_0^{2\pi}\!\int_0^1 r^2\cos 2\theta\cdot r\,dr\,d\theta = 3\underbrace{\int_0^{2\pi}\cos 2\theta\,d\theta}_{= 0}\cdot\int_0^1 r^3\,dr\]
Wynik: \(\displaystyle\oint_\Gamma y^3\,dx + x^3\,dy = 0\)

Zadanie 5 — RR I rzedu: \(y' + 2y = x\)

Tresc
Rozwiazac zagadnienie poczatkowe: \[y' + 2y = x,\qquad y(0) = 1\]

Krok 1: Czynnik calkujacy

\(P(x) = 2\), wiec: \[\mu(x) = e^{\int 2\,dx} = e^{2x}\]

Krok 2: Rozwiazanie ogolne

\[\bigl(y\,e^{2x}\bigr)' = x\,e^{2x}\] Calkujemy przez czesci (\(u = x\), \(dv = e^{2x}dx\)): \[\int x\,e^{2x}\,dx = \frac{x}{2}\,e^{2x} - \frac{1}{4}\,e^{2x} + C\] \[y\,e^{2x} = e^{2x}\!\left(\frac{x}{2} - \frac{1}{4}\right) + C\] \[y = \frac{x}{2} - \frac{1}{4} + C\,e^{-2x}\]

Krok 3: Warunek poczatkowy

\[y(0) = -\frac{1}{4} + C = 1 \;\Longrightarrow\; C = \frac{5}{4}\]
Wynik: \(\displaystyle y = \frac{x}{2} - \frac{1}{4} + \frac{5}{4}\,e^{-2x}\)

Zadanie 6 — RR II rzedu: \(y'' + 4y = \sin 3x\)

Tresc
Rozwiazac rownanie: \[y'' + 4y = \sin 3x\]

Krok 1: Rownanie charakterystyczne

\[r^2 + 4 = 0 \;\Longrightarrow\; r = \pm 2i\] \[y_h = C_1\cos 2x + C_2\sin 2x\]

Krok 2: Rozwiazanie szczegolne

Probujemy \(y_p = A\cos 3x + B\sin 3x\). \[y_p'' = -9A\cos 3x - 9B\sin 3x\] Podstawiamy: \[(-9A + 4A)\cos 3x + (-9B + 4B)\sin 3x = \sin 3x\] \[-5A\cos 3x - 5B\sin 3x = \sin 3x\] \[-5A = 0 \;\Longrightarrow\; A = 0\] \[-5B = 1 \;\Longrightarrow\; B = -\tfrac{1}{5}\]

Krok 3: Rozwiazanie ogolne

Wynik: \[y = C_1\cos 2x + C_2\sin 2x - \frac{1}{5}\sin 3x\]
Pytania?
Jesli jakis krok jest niejasny, zapytaj agenta — moze rozwinac dowolne obliczenie lub wyjasnic metode.
