RR I rzędu — zagadnienia początkowe

Egzamin Zad. 5 Praktyka  &sstrok; ~45 min

Czysta praktyka. Rozwiązujesz kompletne zagadnienia początkowe z Listy 4 — od rozpoznania typu do wyznaczenia stałej. To dokładnie to, co dostaniesz na egzaminie w Zad. 5.

Algorytm egzaminowy (przypomnij sobie z L09–L10)
  1. Rozpoznaj typ: ZR? Jednorodne? Liniowe? Bernoulli?
  2. Zastosuj odpowiednią metodę → rozwiązanie ogólne z \(C\)
  3. Wstaw warunek początkowy \(y(x_0) = y_0\) → wyznacz \(C\)
  4. Zapisz rozwiązanie szczególne

Zadanie 1: \(2(1+e^x)yy' = e^x\), \(\;y(0) = 0\)  (Zad. 4.2c)

Rozwiąż samodzielnie

Typ: ZR. Rozdziel: \(2y\,dy = \frac{e^x}{1+e^x}\,dx\). Prawa strona: podstaw \(t = 1+e^x\).

Rozwiązanie ogólne

\[\int 2y\,dy = \int\frac{e^x}{1+e^x}\,dx\] \[y^2 = \ln(1+e^x) + C\]

Warunek początkowy

\[y(0) = 0: \quad 0 = \ln(1+1) + C = \ln 2 + C \implies C = -\ln 2\] \[\boxed{y^2 = \ln(1+e^x) - \ln 2 = \ln\frac{1+e^x}{2}}\]

Zadanie 2: \(xy' = y + xe^{y/x}\), \(\;y(1) = 0\)  (Zad. 5.2c)

Rozwiąż samodzielnie

Typ: Jednorodne (\(y' = y/x + e^{y/x}\)). Podstaw \(u = y/x\).

Rozwiązanie ogólne

\(y' = u + e^u = g(u)\). Podstawienie: \(u'x + u = u + e^u\), więc \(u'x = e^u\).

\[\frac{du}{e^u} = \frac{dx}{x} \implies e^{-u}\,du = \frac{dx}{x}\] \[-e^{-u} = \ln|x| + C\]

Wracamy: \(u = y/x\):

\[-e^{-y/x} = \ln|x| + C\]

Warunek początkowy

\[y(1) = 0: \quad -e^{0} = \ln 1 + C \implies -1 = C\] \[-e^{-y/x} = \ln|x| - 1\] \[\boxed{e^{-y/x} = 1 - \ln x}\]

Można wyrazić \(y\): \(y = -x\ln(1-\ln x)\). Postać uwikłana jest OK.

Zadanie 3: \(y' - y = xe^{2x}\)  (Zad. 6.2b)

Przykład rozwiązany — pełna procedura

Typ: Liniowe (\(p(x) = -1\), \(q(x) = xe^{2x}\)).

Jednorodne: \(y' - y = 0 \implies y_J = Ce^x\).

Uzmiennianie: \(y = C(x)e^x\). Po skróceniu:

\[C'(x)e^x = xe^{2x} \implies C'(x) = xe^x\]

Całkowanie (przez części):

\[C(x) = \int xe^x\,dx = xe^x - e^x + C_0 = e^x(x-1) + C_0\]

Rozwiązanie ogólne:

\[y = \bigl[e^x(x-1) + C\bigr]e^x = \boxed{(x-1)e^{2x} + Ce^x}\]

Zadanie 4: \(2y' - 5y = 5\sin x + 4\cos x\)  (Zad. 6.2d)

Rozwiąż samodzielnie

Postać standardowa: \(y' - \frac{5}{2}y = \frac{5\sin x + 4\cos x}{2}\). \(p = -5/2\).

Wskazówka: Jednorodne: \(y_J = Ce^{5x/2}\). Uzmiennianie da \(C'(x) = \frac{5\sin x + 4\cos x}{2}\cdot e^{-5x/2}\). Całka typu \(\int e^{ax}\sin x\,dx\) — przez części 2×.

Jednorodne + \(C'(x)\)

\[y_J = Ce^{5x/2}\] \[C'(x) = \frac{1}{2}(5\sin x + 4\cos x)\,e^{-5x/2}\]

Całkowanie \(C'(x)\)

Korzystamy z wzoru: \(\int e^{ax}\sin bx\,dx = \frac{e^{ax}(a\sin bx - b\cos bx)}{a^2+b^2}\):

Dla \(a = -5/2\), \(b = 1\):

\[\int e^{-5x/2}\sin x\,dx = \frac{e^{-5x/2}(-\frac{5}{2}\sin x - \cos x)}{\frac{25}{4}+1} = \frac{e^{-5x/2}(-\frac{5}{2}\sin x - \cos x)}{\frac{29}{4}}\] \[= \frac{-2e^{-5x/2}(5\sin x + 2\cos x)}{29}\]

Analogicznie: \(\int e^{-5x/2}\cos x\,dx = \frac{e^{-5x/2}(-\frac{5}{2}\cos x + \sin x)}{\frac{29}{4}} = \frac{2e^{-5x/2}(2\sin x - 5\cos x)}{29}\)

Łączymy: \(C(x) = \frac{1}{2}\bigl[5\cdot\frac{-2e^{-5x/2}(5\sin x + 2\cos x)}{29} + 4\cdot\frac{2e^{-5x/2}(2\sin x - 5\cos x)}{29}\bigr] + C_0\)

\[= \frac{e^{-5x/2}}{29}\bigl[-5(5\sin x + 2\cos x) + 4(2\sin x - 5\cos x)\bigr]\] \[= \frac{e^{-5x/2}}{29}(-25\sin x - 10\cos x + 8\sin x - 20\cos x)\] \[= \frac{e^{-5x/2}(-17\sin x - 30\cos x)}{29}\]

Rozwiązanie ogólne

\[y = C(x)\cdot e^{5x/2} = \frac{-17\sin x - 30\cos x}{29} + Ce^{5x/2}\] \[\boxed{y = Ce^{5x/2} - \frac{17\sin x + 30\cos x}{29}}\]

Sprawdzenie: Rozwiązanie szczególne \(y_s = -\frac{17\sin x + 30\cos x}{29}\):

\(y_s' = -\frac{17\cos x - 30\sin x}{29}\). Wtedy \(2y_s' - 5y_s = \frac{-34\cos x + 60\sin x + 85\sin x + 150\cos x}{29} = \frac{145\sin x + 116\cos x}{29} = 5\sin x + 4\cos x\) ✓

Zadanie 5: \(xy' = y - \sqrt{x^2 + y^2}\), \(\;y(1) = 0\)  (Zad. 5.2d)

Rozwiąż samodzielnie

Typ: Jednorodne (\(y' = y/x - \sqrt{1 + (y/x)^2}\)). Podstaw \(u = y/x\). Dostaniesz ZR z \(\frac{du}{\sqrt{1+u^2}} = -\frac{dx}{x}\).

Wskazówka: \(\int\frac{du}{\sqrt{1+u^2}} = \ln(u + \sqrt{1+u^2})\) (arcsinh).

Podstawienie: \(u'x + u = u - \sqrt{1+u^2}\), więc \(u'x = -\sqrt{1+u^2}\).

\[\frac{du}{\sqrt{1+u^2}} = -\frac{dx}{x}\] \[\ln\!\left(u + \sqrt{1+u^2}\right) = -\ln|x| + C_1\] \[u + \sqrt{1+u^2} = \frac{C}{x}\]

Wracamy: \(u = y/x\):

\[\frac{y}{x} + \sqrt{1+\frac{y^2}{x^2}} = \frac{C}{x}\] \[\frac{y + \sqrt{x^2+y^2}}{x} = \frac{C}{x}\] \[y + \sqrt{x^2+y^2} = C\]

Warunek: \(y(1) = 0\): \(0 + \sqrt{1} = C\), więc \(C = 1\).

\[\sqrt{x^2+y^2} = 1 - y \implies x^2 + y^2 = 1 - 2y + y^2\] \[\boxed{y = \frac{1-x^2}{2}}\]

Sprawdzenie: \(y(1) = 0\) ✓, \(y' = -x\), \(xy' = -x^2\), \(y - \sqrt{x^2+y^2} = \frac{1-x^2}{2} - \sqrt{x^2 + \frac{(1-x^2)^2}{4}}\). Po uproszczeniu: \(\sqrt{\frac{(1+x^2)^2}{4}} = \frac{1+x^2}{2}\), więc \(\frac{1-x^2}{2} - \frac{1+x^2}{2} = -x^2\) ✓.

Zadanie 6: \(y' - \frac{xy}{2(x^2-1)} = \frac{x}{2y}\), \(\;y(0)=1\)  (Zad. 7.2d)

Rozwiąż samodzielnie

Przepisz: \(y' - \frac{x}{2(x^2-1)}y = \frac{x}{2}\cdot y^{-1}\). Bernoulli z \(r = -1\).

Podstaw \(z = y^{1-(-1)} = y^2\), \(z' = 2yy'\).

Sprowadzenie do liniowego

Mnożymy oryginalne równanie przez \(2y\): \(2yy' - \frac{x}{x^2-1}y^2 = x\).

Z \(z = y^2\), \(z' = 2yy'\):

\[z' - \frac{x}{x^2-1}\,z = x\]

Liniowe! \(p(x) = -\frac{x}{x^2-1}\), \(q(x) = x\).

Rozwiązanie

Jednorodne:

\[\int\frac{x}{x^2-1}\,dx = \frac{1}{2}\ln|x^2-1|\] \[z_J = Ce^{\frac{1}{2}\ln|x^2-1|} = C\sqrt{|x^2-1|}\]

Uzmiennianie: \(z = C(x)\sqrt{|x^2-1|}\). Skracanie daje:

\[C'(x)\sqrt{|x^2-1|} = x \implies C'(x) = \frac{x}{\sqrt{|x^2-1|}}\]

Dla \(|x| < 1\) (w okolicy \(x_0 = 0\)): \(|x^2-1| = 1-x^2\).

\[C(x) = \int\frac{x}{\sqrt{1-x^2}}\,dx = -\sqrt{1-x^2} + C_0\]

Rozwiązanie ogólne:

\[z = (-\sqrt{1-x^2} + C)\sqrt{1-x^2} = -(1-x^2) + C\sqrt{1-x^2}\] \[y^2 = x^2 - 1 + C\sqrt{1-x^2}\]

Warunek: \(y(0) = 1\): \(1 = -1 + C \implies C = 2\).

\[\boxed{y^2 = x^2 - 1 + 2\sqrt{1-x^2}}\]
