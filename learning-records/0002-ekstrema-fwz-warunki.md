## Co zostało opanowane
- Definicja ekstremum lokalnego (minimum/maksimum)
- Warunek konieczny: zerowanie pochodnych cząstkowych → punkty stacjonarne
- Warunek wystarczający: Hesjan H = f''xx * f''yy - (f''xy)^2 → klasyfikacja
- Pełny algorytm: pochodne I → układ = 0 → pochodne II → H → tabelka

## Zadania przerobione
- Zad. 17a: f = x³y + xy³ — H=0, badanie z definicji (rozwiązany)
- Zad. 17b: f = x² + y² - 2ln(xy) — dwa minima (do samodzielnego)
- Zad. 17c: f = e^(2x-y)(2x²-y²) — siodło + maksimum (do samodzielnego)
- Zad. 17d: f = (cos x + cos y)² + (sin x + sin y)² — uproszczenie trygonometryczne (do samodzielnego)
- Rozgrzewka: f = x² + 2y² - 4x + 8y — proste minimum

## Kluczowe spostrzeżenia
- H=0 nie jest rozstrzygające → trzeba wrócić do definicji (Zad. 17a, 17d)
- Przed liczeniem pochodnych warto sprawdzić czy da się uprościć (Zad. 17d)
- e^(coś) > 0 zawsze → przy rozwiązywaniu układu można dzielić
